# M6-015 · 玩家视觉替换为原版 2D 格斗家（配置门）

依赖 M6-014。用户指令替换当前角色模型与动作；原版资源只有待机动画（M6-014 已如实标记）。

范围：`APrototypeCharacter` 构造器视觉块加配置门（cvar `UEMMO.PlayerVisual2D`，默认 1=原版 2D 格斗家，0=回退现有 3D 格斗家管线）；2D 分支在 BeginPlay 隐藏骨架网格（AnimInstance 保持运行以不扰动既有战斗呈现组件），附加朝向相机平面 + FlipBook MID，待机 30fps 循环，随 Facing 翻面，随胶囊自然移动/跳跃；攻击/受击反馈沿用既有音效、伤害数字、命中特效——骨架动画在 2D 分支不可见，以 placeholder 语义如实标注，不伪装成原版战斗动作。

验收：默认启动玩家显示原版格斗家待机动画；移动/跳跃/攻击/受击全流程行为不回归；编辑器全量回归不低于 919 基线且 0 失败（视觉夹具如受波及按其自身契约修正并逐条记录）；Test -Render success=true；包内实机视觉留给用户人工验收。

限制：原版无战斗动作数据（补丁包/帧动画描述未在已提取范围内）；2D 分支攻击瞬间无换帧表现属已知缺口，未来拿到原版动作帧数据后由烘焙管线接入。
