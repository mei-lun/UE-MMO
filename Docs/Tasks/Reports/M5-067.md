## 目标和范围

`URoomSessionSubsystem` 的公共记账入口 `NotifyEnemySpawned` / `NotifyEnemyKilled` 幂等化：

- 出生：仅接受本 Run 新且非空的实例 ID；空 ID、重复出生（无论仍存活还是已死亡后重报）拒绝且无副作用。
- 死亡：仅接受本 Run 活跃集合中的 ID，才增加 `KilledCount` 并触发波次检查；未知 ID、重复死亡、旧 Run ID、非 Running 调用拒绝且无副作用。
- 不改关卡节奏、不改 `WaveSpawner` 正常路径；实例 ID 形如 `melee_grunt_w0_s0`，敌人定义 ID 不充当实例 ID。
- 同步旧 `RoomSessionTests.cpp` 等"任意 Running 死亡可计数"断言为新契约，更新 `Docs/Tasks/接口约定.md` 第 7 节。
