## 根因（两段，均代码/包内日志实锤）

H02 首轮试玩（v2 包）与复测（v3 包）Q 均无反应。两段独立缺陷叠加：

1. **items 无武器映射**：`Data/items.json` 原无 `weapon_definition_id` 字段 →
   FItemDefinition `WeaponDefinitionId = None`（PrototypeCharacter.cpp 原 612-614 行
   "stays None"）→ `UWeaponComponent::ApplyEquippedWeapon` 拒绝绑定（NoWeaponMapping，
   WeaponComponent.cpp:96）→ mount 恒 unbound（v3 包日志 5 次 `weapon mount applied
   (bound=0)`）。
2. **真实游戏启动从不发放物品**：发放仅存在于调试命令 `UEMMODebugInventory(1)`，
   生产启动路径不调用 → 背包空。且 staging 首件 `weapon_training` 映射到
   `weapon_training_sword` 为近战，`IsFireAuthorized` 对 Melee 恒 false
   （WeaponComponent.cpp:246）→ Q 走 `SubmitSkillSlot(1)`（M1 技能槽占位），无开火无弹道。
