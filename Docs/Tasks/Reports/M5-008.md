3. **保存失败的分级语义**：核心 `BuildFromConfig` 因无头进程可能缺包保存器而把保存问题记入 `Summary.SaveProblems`（bSavedToDisk=false）而不翻转布尔；编辑器入口把保存问题视为失败（完整编辑器进程必须产出已保存资产）。本环境实测 -game 与命令let 进程均能实际写盘（save-problems=0）。
4. **测试状态依赖生产路径**：9 个用例都走 null Outer 的默认生产目录 `/Game/UEMMO/Combat/Data` 并真实写盘（与 M1-009 生成即提交的模式一致）；自动化重复运行天然验证幂等更新路径。Foreign 占名用例的自建占位对象仅存内存（MarkAsGarbage 清理，不落盘）。
