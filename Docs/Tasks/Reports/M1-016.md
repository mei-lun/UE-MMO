## 目的

交付一个可受伤、可复位的被动训练敌人（ATrainingEnemy）与其专属训练地图
（/Game/UEMMO/Maps/L_TrainingArena），为后续战斗/房间任务提供打击目标。伤害入口
完全复用 M1-015 的 UHealthComponent::ApplyDamage，不新增任何直接扣血路径；本卡
不实现 AI 主动攻击。

## 实际修改（全部新建）

- `Source/UEMMO/Enemy/TrainingEnemy.h` / `.cpp`：`ATrainingEnemy : ACharacter`。
  - 胶囊 34 半径 / 88 半高（Quinn 约 180cm 身高的标准胶囊）。
  - Quinn 外观采用 **C++ 构造 helper 直载** `/Game/Characters/Mannequins/Meshes/SKM_Quinn_Simple`
    + 单节点循环 `MM_Idle`（与 M0 预览件同一资产、同一播放方式，无需 AnimBP）；
    Mesh 相对旋转沿用 PrototypeCharacter 约定 (0,-90,0)。编辑器脚本在创建与验证
    两处都会核对 Mesh 已赋值，缺失时回退补齐（本次运行中构造 helper 已生效，
    回退未触发，报告 JSON 记录 mesh=SKM_Quinn_Simple）。
  - 默认子对象挂 `UHealthComponent`（`GetHealthComponent()` 访问器）。
  - `ResetEnemy()`：`ResetHealth()` 恢复满血并开启新死亡周期、位置/朝向回到出生锚点、
    `StopMovementImmediately()` 清速度。锚点由 BeginPlay 捕获或 `SetSpawnAnchor()` 显式设置。
  - 受击入口即 `UHealthComponent::ApplyDamage`（接口约定第 5/7 节），无 AIController 逻辑。
- `Source/UEMMO/Tests/TrainingEnemyTests.cpp`：4 条 `UEMMO.Tasks.M1_016.*` 自动化测试，
  NewObject 方式（不加载地图、不依赖 BeginPlay），覆盖组件存在/初值、伤害与复位、
  位置速度复位、复位后再死。
- `Scripts/Editor/create_training_room.py`：create / verify 双模式（verify 由 UE 命令行
  token `UEMMOTrainingRoomVerify` 触发）。
- `Scripts/PrepareTrainingRoom.ps1`（纯 ASCII）：封装 UnrealEditor-Cmd PythonScript
  Commandlet 两次调用（创建+保存 → 新进程重载验证），要求 `Artifacts/training-room-report.json`
  且 success=true。
- `Content/UEMMO/Maps/L_TrainingArena.umap`：由 L_PrototypeArena 复制生成的新资产（已提交 git）。
