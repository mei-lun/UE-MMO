## 实现内容（1eb7277）

- `Source/UEMMO/Weapons/AmmoModel.h`（本卡新文件）：
  - `FAmmoModel` 会话级弹药账本纯值类型——每实例弹匣 `Magazines`
    （按 ItemInstanceId 键控，接口约定 §7 "WeaponStateByItemId 仅记录该
    实例弹匣"）+ 共享备弹池 `ReservePools`（按 AmmoId 键控，
    "ReserveAmmoByType 记录共享备弹"）+ 活动装填窗 `ActiveReloads`；
  - `EAmmoModelError` 显式拒绝枚举（InvalidInstance/UnknownInstance/
    UnknownAmmoType/InvalidCapacity/NegativeRounds/BeyondCapacity/
    BeyondReserveLimit/DuplicateRegistration/DuplicateInstance/
    InvalidDuration/DuplicateReload/MagazineFull/NoReserveAmmo/
    NoActiveReload）+ 明细文本；任何拒绝不改模型状态；
  - 值类型面：`FMagazineState`/`FAmmoReloadState`/`FAmmoReservePool`/
    `FAmmoReloadOutcome` 供后继 WeaponComponent（020/022）读取驱动；
  - 无 World/Actor/UObject/timer 依赖；不落盘（v2 存档归 M5-046）。
- `Source/UEMMO/Weapons/AmmoModel.cpp`（本卡新文件）：
  - `RegisterAmmoType`：注册 AmmoId→(MaxReserve, 初始备弹)；非法 id 文本
    （复用 `IsValidDefinitionIdText`）、负数/超 `MaxAmmoReserve` 上限、初始
    超 MaxReserve、重复注册全部拒绝；
  - `InitializeInstance`：显式初始载弹（模型不自造满匣策略，调用方传
    Capacity 即满匣）；全零 guid/未知 Ammo/容量出 1..999/负载弹/超容量/
    重复初始化拒绝；
  - 两阶段装填事务：`BeginReload(InstanceId, Now, Duration)` 只开窗
    （时钟由调用方注入，模型不读 World 计时），拒绝顺序未知实例→非法时长
    （非有限/负）→重复开窗→满匣（"满弹匣不换弹"）→空备弹（"无备弹不换
    弹"），成功不移动任何弹药；`CompleteReload` 原子转移
    granted = min(capacity − loaded, reserve)——唯一移动弹药的入口，窗口已
    关则拒绝（"重复完成回调不赠弹"）；`CancelReload` 只关窗不转移
    （"切换/死亡取消不得转移弹药"）；
  - 查询面：`FindMagazine`/`GetReserveRounds`（未注册返回 -1 区分空池）/
    `GetRemainingReloadSeconds`（到点钳 0，完成回调仍是调用方职责）/
    `IsReloading`/`NumMagazines`/`NumAmmoTypes`/`Reset`。
