## 根因（v6 包用户会话实证，2026-10-13 01:34）

1. bound=1（绑定/恢复正常），14 次 Q 全部授权通过（操作日志全为
   `Pressed Q (WeaponFire)`），但 M5-058 发射日志**零条**。
2. 代码实锤：`HandleWeaponShotCommitted` 的 stale-generation 守卫
   `IsBindingGenerationCurrent(BoundWeaponGeneration)` 为**严格相等**比较，而
   `BoundWeaponGeneration` 唯一赋值点在 `ApplyWeaponBindWiring()`——该方法
   **没有任何生产调用者（只有测试在调）**。真实路径该值恒 0 ≠ 当前 generation，
   每一发提交的交付回调（伤害/曳光/音效/日志）被整体静默丢弃。Q 实际在扣弹，
   但永远打不出任何效果。这同时解释了 v4/v5/v6 全部现象与"自动化全绿"的矛盾。
3. 诊断弯路（如实记录）：曾怀疑音效未 cook——用 UnrealPak -List grep .pak 零命中；
   实际 Package.ps1 一直带 `-cookall` 且包为 IoStore（内容在 `.ucas`），.pak 只装
   非资产文件，grep 结论无效。音效一直都在包里，无声的真因就是交付回调被杀。
   为留下确定证据，新增包内解析套件由零豁免门禁证明（见验证节）。
