### C++ 最小接线（任务卡允许范围）

- `DNFMCharacterVisualSet.h/.cpp`：新增 `UFUNCTION(BlueprintCallable) static FString BuildManifestIntoSet(json, textures, OutSet*)`——纯委托到既有 `BuildFromManifestJson`（M6-021 引用签名零改动）。原因：python 只能调 UFUNCTION，且 UHT 禁止 BlueprintCallable 非 const 对象引用；实测 5.8.3 python 绑定对"bool 返回 + FString& 出参"这组签名会丢返回值且错位（probe 记录在案），故错误文本走 FString 返回值（空=成功）。
- `PrototypeCharacter.cpp`：①构造器把导入数据资产**软路径**绑到 `DNFMVisual->DefaultVisualSet`（工程无玩家蓝图——PrototypeGameMode 直接生成 C++ 类，组件默认值即绑定点；资产在 git 忽略目录，缺失时保持 M6-021 文档化的无图降级）；②`ApplyDNFMVisualIfEnabled` gate=1 激活路径：软路径加载材质 → `SetMaterialInterface`，再从绑定集的 rest 帧 0 取 `PivotPx.Y`（y-down 画布中 pivot 即脚底、画布顶即头顶）对胶囊全高 192cm 调 `SetWorldScaleFromStandingHeight`，日志输出标定值。激活每 pawn 一次，无逐帧开销。
- `DNFMCharacterVisualComponent.h`：仅修正材质契约注释（V 翻转依据，见下），无行为改动。

### 数据层修正（M6-020 产物一处）

manifest 的 earthbreak 帧 5 `duration_ms=0` 被 M6-021 冻结契约拒绝（"零时长帧导入即拒"）。在 `Scripts/DNFM/prepare_fighter_visual_set.py` 输出端 clamp 为 1ms（带注释）并重跑生成器：**重生成前后 manifest 仅此 1 个 JSON 值不同，页 PNG 逐字节不变（sha256 6131f95c… 不变）**；钳制前 manifest 存 `pre-analysis/manifest_before_duration_clamp.json`。manifest 的 action_id 与 M6-019/M6-023 映射表键完全一致（rest/move/jump/attack1/...），presenter 映射表无需改动。

### 实图驱动的两处资产缺陷修正（证据驱动）

1. **材质 SM6 编译失败**（游戏进程日志 `Failed to compile Material for platform PCD3D_SM6, Default Material will be used in game`，plane 完全不渲染）：`recompile_material` 给出 `(Node Multiply) Arithmetic between types float2 and float3 are undefined`——VectorParameter(float4) 直接参与 TexCoord(float2) 乘法所致。修复：参数输出加 ComponentMask(R,G)，import 增加编译错误校验。
2. **精灵垂直翻转**（首张实图中角色倒立）：直接调用公开函数 `ComputeFrameQuadTransform` 复算与 plane 实际变换一致，排除组件状态问题；定位为 `/Engine/BasicShapes/Plane` 的 UV v=0 在 quad 局部 −Y（世界下方）一侧，而页矩形 y-down 自顶部起——线性映射把图顶采到世界底。修复：材质图内对 V 取 `1−v`（页顶行落在 quad 局部 +Y = 相机 Up，符合方案 §5.2 的原意）。注：M6-015 报告所称"已人工核验方向"未覆盖垂直朝向（其验收只断言了法线与宽度轴），本次为首个真实的垂直方向核验，组件头注释已同步修正。

## 已知限制

1. **gate 仅在 BeginPlay 求值**：`ApplyDNFMVisualIfEnabled` 无运行时 CVar 翻转回调（M6-021 既有行为，未改）；实图走 `-DPCVars=UEMMO.PlayerDNFMVisual=1`。运行时切门暂需重生成 pawn。
2. **玩家绑定走 C++ CDO 而非蓝图**：工程不存在玩家 BP（GameMode 直接用 C++ 类），故 DefaultVisualSet 以软路径写在构造器；fresh checkout 无导入资产时保持"无图降级 + 一次性 Warning"。
3. **材质复用节点的 5.8.3 编辑器 python quirk**：`delete_all_material_expressions` 在复用资产上偶发留下 2 个哑节点，import 以"清理循环 + 计数不符即整资产重建"兜底（已记录）。
4. **earthbreak 帧 5 时长 1ms**：源数据 delay 0，契约拒绝零时长，钳制为 1ms（视觉上等于跳过，帧序与像素不变）。
5. 截图验收用 `DevSetMoveAxes`/`SubmitCombatInput` 驱动（非真实键盘，沿用 M6-015 惯例）；单页 manifest（136 帧全在第 0 页），多页路径代码就绪但未有多页真实数据。
6. M6-015/016 的 M6-014 Spine 预览证据链不受影响；其"方向已核验"表述以本报告为准修正（垂直朝向当时未被断言）。
