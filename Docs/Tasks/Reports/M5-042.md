## 目标和范围

使用现有 UE 运动/碰撞能力实现地面平台（X/Y 方向/斜向归一化、停止/边界，Z 由地面碰撞；配置决定速度/加速度；Y 不启用平面锁）；切座位后镜头跟车辆地面锚点，退出还原角色锚点；司机之外不能控制；首版车辆不跳跃/飞行。

执行方式（用户要求多 agent 加速）：实现主体由并行子代理（Agent J）落盘四个实现文件后中断（SendMessage 探针确认无活动任务）；协调者接管补写全部测试与验证闭环。

实现提交（本卡范围五文件，其中四个由 Agent J 落盘、测试文件由协调者补写）：

- `Source/UEMMO/Vehicles/VehicleMovementComponent.h/.cpp`：`UVehicleMovementComponent : UActorComponent`——`Configure()`（从 hull 的 FVehicleDefinition 读 MaxSpeedCmS/AccelerationCmS2，制动默认=加速度，重配刷新 override）；`SetDriveInput(X,Y)`（权限门：司机在座+控制未暂停+活 hull；拒绝即清油门，司机中途丢失必然滑行减速而非带旧输入继续）；`TickMovement(dt)` 公共确定性步进（TickComponent 转发至此，组件自带 tick 不依赖 hull actor tick）；权限注入面 `SetDriverPresent/SetDriverPresenceProvider/SetDriveControlsSuspended/SetControlSuspensionProvider`（生产接线读 FSeatOccupancyModel 走 provider）；`SetBrakingDecelerationCmS2`（非有限/非正拒绝）；`GetPlanarVelocity/IsGrounded/IsDriveInputAccepted`。
  - 垂直通道：世界自身重力积分 + hull 根盒扫掠落地，落定后保持 1cm 悬浮工作间隙（下一次平面扫掠永不触地，消除贴地 touch 分类的不确定性）；地面探测 7cm、地板法向 Z≥0.7 才算落地；Z 由碰撞独自决定，无跳跃/飞行输入。
  - 平面通道：斜向归一化（单位方向×标量加速度，M1-029 先例）+ 全向量限速（斜向极速=直线极速）；无输入按制动减速度滑行至精确零；扫掠滑动移动——撞击把剩余运动投影到接触面（正面停、斜角滑），进入墙面的速度分量同时从速度中移除，三次数迭代内墙-滑-角收敛，双墙角落停止不抖动。Y 是一等驱动轴，无平面锁。
- `Source/UEMMO/Vehicles/VehicleCameraBridge.h/.cpp`：`UVehicleCameraBridge : UActorComponent`——`BridgeToVehicle`（SpringArm 重挂到 hull 根 + 定义相机值：pivot=origin+CameraHeightCm、boom=CameraDistanceCm、pitch=CameraPitchDeg、M0 固定 -90 yaw 保留；跟随由引擎变换传播免费获得，桥自身零逐帧工作；悬挂 pawn 侧 rig tick 防止两套锚点打架；幂等：同 hull 重桥为无副作用 no-op，换 hull 先还原再重挂）；`RestoreCharacterAnchor`（还原保存的父/boom/旋转、按 rig 自身 M1-030 纯函数+一次地面 trace 快照到角色锚点、恢复 tick）；hull 一次性销毁广播自还原订阅（接线缺口也不会把相机留在死 hull 上）；桥自身 EndPlay 先还原。
- `Source/UEMMO/Tests/M5VehicleMovementTests.cpp`（协调者补写，9 用例）：完整世界形态（GameInstance+world context+InitializeActorsForPlay+SetGameMode+BeginPlay，039/041 教训）；①Configure 拒绝无定义 hull/装载 700/900/制动 override 非有限非正拒绝/重配重置；②权限门（无司机/暂停/死亡拒绝并清油门、provider 覆盖手动旗、组件 tick 转发 10 帧加速 150、死 hull 滑行归零）；③直线 X/纵深 Y 位移符合钳位加速积分（46 帧斜坡 270.25cm+14 帧 700 上限 163.33cm≈433.6cm）、顶速窗口 700cm/60 帧、松输入精确停且不蠕行；④斜向单帧增速=直线（无 √2 加成）、斜向极速=700（非 990）、顶速窗口每轴 494.97cm 且两轴均匀；⑤墙正面停（全程无穿透检查点、持油门零蠕行、无深度滑移、悬浮高度不变、松输入后不动）；⑥镜头桥跟随（挂 hull 根/boom 650/pitch -18/-90 yaw/pivot=origin+260/tick 悬挂、teleport 后 X/Y/Z 全跟）+ 还原（父/boom 1700/tick 恢复、锚点与 rig 自身 M1-030 纯函数同源构造一致）+ 幂等还原 no-op；⑦无定义 hull 拒桥不动 rig、重复桥 no-op 不重捕桥态、换 hull 先还原；⑧hull 销毁广播自还原 + 桥 EndPlay 自还原 + 已毁桥不再应答；⑨VehicleSceneCapture 渲染采集伴侣（ClientContext，headless 静默跳过）。
