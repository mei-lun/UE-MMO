## 目的

按任务卡把 M0 的单序列动画覆盖（`UpdateAnimation` 每次状态变化 `PlayAnimation` 从 0 重播）替换为 AnimBP 驱动的动画层：原生 `UPrototypeAnimInstance` 导出 Speed / LocalVelocity（角色本地空间）/ Direction / IsFalling / IsMoving / PoseIndex，生成的 AnimBP 用 2D BlendSpace（Speed×Direction，引擎现成 Unarmed Jog 八方向动画）连续混合待机/八方向移动，并用姿态混合列表接 Jump/Fall/Land。LocalVelocity 映射为纯函数先红后绿。

## 图编辑实际方法（梯队说明）

1. **梯队①（纯 Python EdGraph 搭状态机）不可行，已用引擎源码逐项核实**：`UEdGraphPin` 在 5.8 不是 UObject（无 Python 包装类，`get_editor_property('pins')` 不可用）；`UEdGraphNode`/`UEdGraph`/`UEdGraphPin`/`UAnimGraphNode_Base` 均无任何 `AllocateDefaultPins`/`CreateNewGuid`/`MakeLinkTo` 类 UFUNCTION（grep 计数 0），pin 分配无 Python 调用面；5.8 新增的 `FBlueprintGraphPin`/`UBlueprintGraphPinLibrary`/`BlueprintEditorLibrary` 的 pin API 全部限定 `UK2Node*`（动画图节点不是 K2Node）；探针实测 `unreal.new_object(AnimGraphNode_*)` 可建对象但无 pin 分配途径。纯 Python 连一个可求值的动画节点都接不进 Output Pose。
2. **实际采用：梯队② 的"扁平混合图 + C++ 侧姿态参数"，用卡面允许的"缺接口时用明确编辑器工具补齐"**——图编辑由原生 `EditorBuildLocomotionGraph` 完成（`FGraphNodeCreator`/`UAnimGraphNode_*`/`MakeLinkTo`，即 AnimGraph 编辑器同款引擎 API），调用入口仍是 Python 资产脚本；未手写任何 uasset 字节。
3. **未建状态机**：Idle/Move/Jump/Fall/Land 过渡由 BlendListByInt（0.15s 混合 + C++ PoseIndex 驱动）承担，BlendSpacePlayer 在其下持续求值——行为验收（起跳/落地回 Idle、待机/移动不重播）全部满足；状态机（状态节点+转移规则图）需要的编辑器 API 面更大，未在本卡冒险。

## 已知限制

- **无移动中/跳跃瞬间的截图**：截图时机写死在 M0 的 `PrototypeSmokeRunner`（8s 采集，属其他任务文件不可改），`-DumpMovie` 在本机游戏进程未产出文件（无编码器日志、无输出）。已如实以数值证据（dx/dy/跳跃高度与基线一致）+ 待机姿态截图 + 逐帧混合语义佐证；四方向移动的观感（Jog 八方向插值是否好看）属 H01 人工试玩范围，本报告不代签。
- **未用 AnimGraph 状态机**：过渡由 BlendListByInt 承担（见"图编辑实际方法"）；若后续需要转移规则（如按高度切姿态）需引入状态机编辑面。
- BlendSpace 只用 Jog 组（键盘二值输入实际速度 280–420 cm/s 与 Jog 匹配）；Walk 组动画已就位未接入（未来模拟量输入可用）。后退方向在 +180 与 -180 各放一个采样（同一 Jog_Bwd）以保证 ±180 邻域混合覆盖，未启用 `bWrapInput`。
- `BlendParameters` 轴以 C++ 反射写入（Python/普通反射面读不到 C 数组属性），因此 verify 报告以采样值域 + 重编译结果间接佐证轴范围生效（若范围仍是默认 0..100，420 采样会在加载时越界报错——修复前的一次运行确实产生了 9 条越界 Error，修复后新进程加载 0 错误，前后对照即证据）。
- 探针产生的临时资产（/Game/UEMMO/Animation/Probe）只存在于内存未保存，最终 Content/UEMMO/Animation 仅含两个提交资产。
- 偏离任务简报两处：简报预估"可能只有 1D Speed"——实际引擎 Unarmed Jog 组八方向齐全，按卡面用了 2D Speed×Direction；简报建议的纯 Python 图编辑不可行，改用卡面"明确编辑器工具补齐"路线（原生编辑器辅助函数 + Python 编排），理由与证据如上。
