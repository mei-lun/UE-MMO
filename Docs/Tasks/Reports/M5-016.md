### 配置语义（测试逐条覆盖）

| 场景 | 行为 |
|---|---|
| 默认策略落地 | Knockdown 0.45s → Recovering 0.25s → Free（边界 10.45/10.70 逐 tick 断言） |
| 策略授予 0.9/0.1 | 边界移动到 100.90/101.00，零类代码改动 |
| 非法授予（负数/非有限） | 回退旧常量 0.45/0.25，deadlines 不被毒化 |
| 保护期命中 | Knockdown 与 Recovering 两阶段 `NotifyHitReceived` 均整体拒绝 |
| 普通跳跃落地（无发射标记） | 不倒地、无保护、只记录地面接触 |
| 受击空中落地（真实 launcher 命中后落地） | 开启恢复流程，完成后回 Free |
| 重复落地 | 拒绝且不重开/延长计时（原 deadline 站立） |
| 死亡 | `BeginLandingRecovery` 拒绝，Dead 不恢复 |
| 复位链（服务级） | 玩家/敌人速度+待发冲量归零、输入缓冲空、保护标志清、池满/周期重开/窗口关、HP 满、Free |
