## 限制

1. **截图材质呈黑**：master 材质图经 API 验证已连接并编译（connect 返回 True、recompile 无错误、
   Constant3Vector 直连 BaseColor 也呈黑），SceneCapture2D 在 -ExecutePythonScript 无 tick 会话中
   渲染不出材质/灯光变化（改灯强度像素不变）。数据链（槽→MIC→parent→贴图）已逐级验证正确；
   请在 GUI 编辑器打开 /Game/UEMMO/ArtValidation/DNFArt 目视复核真实材质表现。
2. **动作冻结帧呈绑定姿势**：SingleNode set_position 后无世界 tick 可驱动求值（编辑器 tick API
   在该会话不可用）；动作本身已导入且时长正确，可在 GUI 中播放查看。
3. 验收命名空间的每动作临时 SkeletalMesh/Skeleton 保留（供跨进程预览），正式接入时应以绑定
   姿势骨架为唯一骨架重新整理导入（属未来功能任务的资产整理步骤）。
