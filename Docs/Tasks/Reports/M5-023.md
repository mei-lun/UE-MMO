## 集成决策（卡面授权范围内）

1. **单一时钟源**：策略不持时钟、不读 World——候选 `FShotContext::CommittedAtSeconds` 就是组件注入的火时钟读数（022 `SetFireClockProvider` 语义，Pause 冻结）。暂停/HitStop 对节拍的影响由此天然成立，测试逐一钉住。
2. **每帧单发守卫为纵深防御**：组件冷却门（60/FireRateRpm）已阻断同帧二发；策略的 `Now <= LastAdmission` 守卫在组件冷却被配置归零（RPM 极大）时兜底，并为暂停冻结提供命名拒绝。两者都不需要策略自己读帧号。
3. **锚留松键**：`NotifyShotReleased` 只清同帧标记，间隔锚保留——连射节拍是武器属性而非逐扣状态；"松开后不残留"钉为无散发、无扣账、无持有容量（授予是事务性的），而非清除节拍。
4. **输入层 hold 模式（移交 M5-033）**：按住期间每帧 `TryFire` 一次，命中提交后同帧 `ReleaseFire` 关闭在飞窗（hitscan 瞬时结算）。该模式是 023 测试 rig 的驱动方式，也是 033 生产接线的约定；半自动/连射的语义区分在输入层轮询方式（按下沿单发 vs 按住轮询），策略只提供节拍与守卫。
5. **拒绝复用 022 词汇**：策略拒绝统一映射 `EFireReject::ReservationFailed` + 明细（hitscan-only / 每帧单发 / 间隔未到），不新增平行枚举。

## 限制与移交

- 仅授权 hitscan；projectile 交付与容量归 M5-024 策略，散射/多弹丸归 M5-025——均经 `SetFirePolicy` 注册各自策略文件。
- `SetShotIntervalSeconds` 的生产取值（按武器定义 FireRateRpm 换算 60/RPM）由集成者在注册策略时设置；当前默认 0 = 让位组件冷却。
- 策略级间隔与组件冷却独立：若两者配置不一致，生效间隔 = 二者较严者；测试只钉较严层语义，配置一致性归 033 接线。
- 自动化不等同真实键鼠试玩；本卡为纯逻辑节流，无人工关卡项。
