## 目的

按接口约定第 3 节实现 `UAttackDefinition : UPrimaryDataAsset`（字段名内含单位：Frames/Seconds/cm，秒与帧不混用）和单条纯校验函数 `bool ValidateAttackDefinition(const UAttackDefinition& Attack, FText& OutErrors)`。校验非法时把所有问题用 `"; "` 连接写入 `OutErrors`，每条包含字段名；合法时返回 true 且 `OutErrors` 为空。本卡不创建任何内容资产（DataAsset 生成是 M1-009），`AllowedNextAttacks` 不做跨条目存在性校验。

## 实际修改

- `Source/UEMMO/Combat/AttackDefinition.h`（新建）：`FAttackFrameWindow`（USTRUCT）+ `UAttackDefinition`（UCLASS，16 个 UPROPERTY 字段，初值按接口约定：DurationFrames=0、BaseDamage=0、AttackCoefficient=1.0、HitOffsetFromFeet=(95,0,90)、HitHalfExtent=(85,50,70)、HitStopSeconds=0.04、bPlaceholderAnimation=true）+ 自由函数 `ValidateAttackDefinition` 声明。
- `Source/UEMMO/Combat/AttackDefinition.cpp`（新建）：`ValidateAttackDefinition` 实现，纯校验，不创建/修改资产。
- `Source/UEMMO/Tests/AttackDefinitionTests.cpp`（新建）：9 个自动化测试（前缀 `UEMMO.Tasks.M1_007.*`），全部用 `NewObject<UAttackDefinition>()` 构造，不需要 World。

### 窗口类型选择：新增 FAttackFrameWindow（USTRUCT），不是直接用 FCombatWindow 成员

选择为 `ActiveWindow`/`CancelWindow` 新增 `FAttackFrameWindow`（`StartFrame/EndFrame` 为 UPROPERTY，可被编辑器序列化进 DataAsset），其 `IsValid/Contains/Crosses` 内部转调临时构造的 `FCombatWindow`。理由：M1-005 的 `FCombatWindow` 是纯 C++ struct（非 USTRUCT、且本卡禁止修改 CombatWindow.h），作为裸成员无法加 UPROPERTY，DataAsset 编辑器工作流（M1-009 生成资产后需要查看/微调）拿不到帧窗口数据；用 USTRUCT 镜像 + 转调让半开窗口语义仍只在 `FCombatWindow` 一处定义，不复制逻辑。`ToCombatWindow()` 公开转换供 M1-011 等运行时使用方取回运行时窗口类型。

### 校验规则实现对照

- `DurationFrames > 0`，否则报 `DurationFrames`。
- 两个窗口各自独立检查：`StartFrame >= 0`、`EndFrame > StartFrame`、`EndFrame <= DurationFrames`，报错含 `ActiveWindow` / `CancelWindow`。
- `BaseDamage` 有限且 >= 0；`AttackCoefficient` 有限且 > 0。
- `HitHalfExtent` 三分量全部有限且 > 0；`HitOffsetFromFeet` 三分量有限（符号有意义，允许负）。
- `KnockbackSpeed`/`LaunchSpeed`/`HitStunSeconds`/`HitStopSeconds` 有限且 >= 0。
- `ClipStartSeconds`/`ClipEndSeconds` 有限且 >= 0 始终检查；顺序（`ClipEndSeconds >= ClipStartSeconds`）仅在 `!Animation.IsNull() && !bPlaceholderAnimation` 时检查（软引用用非空路径 `/Game/UEMMO/Test` 测试）；占位动画不校验片段区间。
- `AllowedNextAttacks`：本卡只做单条校验，跨条目存在性校验属于 M1-009/010 目录任务；函数以 `const UAttackDefinition&` 为参数，可被目录循环调用（头文件注释与本报告均写明该集成入口）。
