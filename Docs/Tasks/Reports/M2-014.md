- 新建 `Source/UEMMO/Tests/RoomScenarioTests.cpp`（前缀 `UEMMO.Tasks.M2_014.*`，5 个测试）：
  1. `FullClearEventSequenceClearsExactlyOnce`：波1（2 只）→ 逐个击杀 → 精确 1.0s 等待 → 波2（3 只）→ 击杀 → Cleared；记录并断言实际事件序列（时间戳+类型）：`RunStarted → WaveStarted(w0) → Spawn×2 → Died×2 → WaveStarted(w1) → Spawn×3 → Died×3 → RunEnded`，波1 开始时刻 = 末次死亡 + 1.0s（窗口 [T+1.0−0.02, T+1.0+0.15]，实测精确命中 1.5s）；Spawn=5、Killed=5、RunEnded 恰 1 次；另验证 GetRunResult/IsRewardEligible 与重复 MarkCleared 拒绝。
  2. `PartialLastWaveStaysRunningWithoutSettlement`（负例，先写）：最后一波只杀 2/3 → 推进 5s 仍 Running、无 RunEnded、波索引不变、无迟到刷怪；最后一只死亡后才 Cleared。
  3. `PlayerDeathFailRetryThenFreshClear`：玩家死亡（HealthComponent 致死 → 真实 PlayerDied 广播）→ Failed（RunEnded 恰 1、cleared=0）→ 2s 窗口无迟到刷怪 → RetryRoom 摧毁且仅摧毁旧 run 敌人 → 新 RunId → 完整清关 → Cleared（RunEnded 共 2）。

  5. `ThreeConsecutiveRunsLeaveNoResidue`：3 局连续（每局 清关 → LeaveRoom → 重进）；每局 Spawn=5、击杀=5、Cleared 恰 1 次；每局新增 Actor 恰 5 个、局末存活 0；局内波0 击杀后 0.5s 波索引仍为 0（计时器无跨局残留），满 1.0s 才开波1；3 局共 Started=Ended=3，无委托堆积。
