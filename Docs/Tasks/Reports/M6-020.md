## 实现内容

新增 `Scripts/DNFM/prepare_fighter_visual_set.py`（纯标准库 + Pillow 12.3，确定性，可重跑，
`py -I` 运行）：

1. **对齐约定复现**：自包含实现 `restore_dnf_atlas.crop_frame`/`get_atlas` 语义——
   atlas.sqlite `rect` 为 Unity 左下原点页内像素，裁剪时 y 翻转；frame `offset` 把裁剪放回
   500x500 原始画布（reference 帧仅空矩形时跟随，与 crop_frame 一致）；内容 bbox 后按
   `bbox 角 + animation position` 放入"位置空间"（原点=脚底/动作锚点，y 向下）。衣装各层共享
   同一画布锚点约定，故各层用同一 position 合成即为像素级正确相对对齐。
2. **`--body-only` 模式（里程碑1）**：rest/move/attack1/jump 四动作按 ue_ready animation.json
   + atlas.sqlite + ft_body0000 页 PNG 合成，逐帧 cell = 各层内容并集盒 + 2px 透明边距，
   逐帧记录 pivot_px（锚点在 cell 内位置）与包围盒。
3. **`--mapping` 插件式全衣装模式（里程碑2 就绪）**：按 M6-019 卡契约
   `actions[].frames[].layer_frames 每部件 {atlas_id, frame_index, offset, page}` 读取映射；
   `offset` 作为与 atlas.sqlite 的**交叉校验数据**（不一致即硬报错，绝不静默采用）；
   另支持 `src_rect_px`（前后拆层裁剪）与 `placement_delta`（显式位移）扩展键；
   body 条目可选（存在即交叉校验）。draw_order 覆盖检查：衣装层必须有条目或显式 missing。
4. **§10 拦截**（全部硬报错 exit=2，已实测）：非单位 scale、非零 rotation、flip_copy_type≠0、
   非白 color_rgba、palette 页、页纹理未解析、分数矩形、cell 超页尺寸（禁止静默缩小）、
   映射帧数与动画不符、映射 offset 与 atlas 不符、未知映射键（严格契约）。
5. **分页**：≤2048x2048 固定页尺寸，行主序 shelf 装箱，保留 2px 透明边距；超页另开页并记录
   `cells_on_page`；单 cell 超页硬报错。
6. **manifest 契约**：顶层 `generator/character/outfit/source_root/pages/actions/missing`，
   action `action_id/source_ani/source_sha256/loop/layers/draw_order/frames`，frame
   `index/duration_ms/page/uv_rect_px/canvas_size_px/pivot_px/pivot_definition/layer_frames/
   flip_copy_type/scale/rotation_degrees/source_frame/events` 全部按任务卡字段名实现；
   附加审计字段（`manifest_version/mode/coordinate_space/verification/inputs/content_bbox_px/
   layer_frames.page`，其中 page 为 M6-019 卡明确要求）。events 收录 audio_tags/audio_loop_tags。
7. **预览**：每动作横向条带 PNG（NEAREST 2x），红基线+橙点标 pivot，便于人工核对脚底。
