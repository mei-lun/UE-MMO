## 目标和范围

修复"入口接受但没有可运行波次"的失败路径（不改敌人/技能数值、不造默认敌人）：

- 触发器在 `StartRoom` 前解析并验证房间定义（非空、有波次）与敌人定义（资产可加载）；缺配置/资源时拒绝进入、会话保持 Idle 可再次触发，日志含可定位原因（资产路径/房间 ID）。
- 已进入 Running 而 `BeginWaves` 被拒时，以 `FailRun` 结束（首终态获胜下为安全幂等），绝不停留在无怪 Running；不产生 Cleared、奖励或残留出生。
- HUD 重试上下文可用性（明确定义）：仅开波成功的 Run 下发 `SetRoomRetryContext`；入口被拒（无 Run）与开波被拒（Failed Run）均不下发，HUD 既有守卫（`PrototypeHUD.cpp:996-1019`）会拒绝重试按钮并记录 "retry unavailable"，结果界面保持。
- 恢复有效资源后，玩家再次进入激活区即可正常开局。

优先本链原因同 M5-067：用户指定按接手指导执行 M5-067→074 适配链。
