### 限制与后续

- Poise 池/浮空计数/空中窗口是"每受害者组件一份"状态；组件less 靶（纯
  Health 盒子）不带池与窗口，TrainingEnemy 的计数沿用旧字段（组件 API 透传）。
- 免伤（bImmuneDamage）+ 带池目标：解析伤害为 0 → 无压力，池永远不会被纯
  免伤命中磨破；poise_damage 字段入契约时一并修正。
- Poise 回复用注入输入时钟懒结算（读时恢复）；不注入时钟的持有者池冻结
  （安全侧：只影响回复速度，不影响门控正确性）。
- `Hit.StunSeconds` 载荷从"definition 原值"改为"实际准许值"：默认策略下数值
  相同（旧断言全绿），仅门控拒绝时载荷更真实。
- 波次敌人（MeleeEnemy）自本卡起受每浮空周期 2 次上挑上限与 2.5s 空中窗口
  约束（旧文档化限制"M2 敌人不受上限"按契约 §10.2 的统一表面要求解除）；
  全量 623 绿含 M2 场景回归。
- 本卡未触碰 TASKS.md/HANDOFF.md/TrainingEnemy/MeleeEnemy（协调者维护总表；
  敌人类零改动）；自动化不等同真实键鼠试玩。
