## 目的

按任务卡把 M0 的横版固定镜头参数与逻辑单一组件化（yaw 固定 -90、俯角 18°、FOV 55、臂距 1700cm 初值全部保留），并新增"地面锚点"跟随：锚点 Z 只来自角色脚下向下检测的落地点（跳跃 Z 永不进入锚点），X 平滑跟随并夹在可配置房间界限（默认 ±1200cm），Y 只跟随 25%（纵深移动 400cm 锚点约变化 100cm）。镜头不围绕角色旋转，Facing 反转不改 yaw。核心数学提取为无 World 可测的纯函数，先红后绿。

## 实际修改

- `Source/UEMMO/Character/SideViewCameraComponent.h`（新建）：
  - `USideViewCameraComponent : USpringArmComponent`（采用任务卡允许的"派生/组合"路线中派生弹簧臂的方案：组件本身即 CameraBoom，挂到角色 RootComponent 后必然注册并参与渲染，比 `UActorComponent` 内嵌运行时 attach 更稳）；构造函数内 `CreateDefaultSubobject<UCameraComponent>(TEXT("SideViewCamera"))` 作为子对象并 `SetupAttachment(this)`，FOV 55、`bUsePawnControlRotation=false`。
  - 固定取景：`SetUsingAbsoluteRotation(true)`，旋转只在 `ApplyConfig()`（BeginPlay 调用一次）经 `ComputeCameraRotation()` 设置为 (-18°, -90°, 0)，Tick 每帧**只** `SetWorldLocation`，从不改旋转——Facing 反转在结构上不可能改变 yaw。`bDoCollisionTest=false`、`TargetOffset=0`（M0 的 TargetOffset Z+100 与胶囊半高 96 合并为 `PivotHeightAboveGround=196`，站立取景与 M0 完全一致）。
  - `FSideViewCameraConfig`（USTRUCT，BlueprintType，EditAnywhere 可配）：FieldOfView=55、ArmLength=1700、PivotHeightAboveGround=196、YFollowRatio=0.25、RoomMinX/RoomMaxX=±1200（任务要求的可配置界限）、FollowSpeed=8、GroundTraceDistance=100000。
  - 纯函数（命名空间 `UE::UEMMO::Tasks::M1_030`，inline 无 World 可测）：`ClampToRoomBounds`（X 界限夹取）、`ApplyYDamping`（参考 Y + 位移×比率）、`ComputeAnchorZ`（仅 GroundZ+高度，签名里就没有 pawn Z）、`ComputeCameraYaw`/`ComputeCameraRotation`（任意 Facing 恒返 -90/-18）、`ResolveGroundZ`（命中且有限用命中值，否则回退传入值）、`SmoothFollowAxis`（1-exp(-speed·dt) 指数插值，速度≤0 直接贴合）、`ComputeAnchorLocation`（PawnLocation+GroundZ+ReferenceY+Config → 目标锚点：X 夹界限、Y 阻尼、Z 锁地面）。
  - 常量：`SideViewCameraYaw=-90`、`SideViewCameraPitch=-18`、`GroundTraceStartClearance=50`。
- `Source/UEMMO/Character/SideViewCameraComponent.cpp`（新建）：每帧 `TickComponent`——`TraceGroundZ()` 从角色位置上方 50cm 向下线检测（ECC_Visibility，忽略自身，`FCollisionQueryParams` 带 Owner），经 `ResolveGroundZ` 得 GroundZ（无 World/未命中回退上次值；BeginPlay 初值 = 角色 Z − 胶囊半高，随后检测覆盖）；`ComputeAnchorLocation` 得目标锚点；X 经 `SmoothFollowAxis` 平滑，Y/Z 直接采用（Y 已是阻尼值、Z 必须锁地面防跳跃抖动）；`SetWorldLocation(CurrentAnchor)`。BeginPlay 记录 `ReferenceY`（起始角色 Y，Y 阻尼参考点）并初始化锚点，避免首帧从零漂移。
- `Source/UEMMO/PrototypeCharacter.cpp`（修改，接线）：include 换为 `Character/SideViewCameraComponent.h`（本目录相对路径），构造函数中 M0 的 CameraBoom/Camera 九行设置整体删除，替换为 `CameraRig = CreateDefaultSubobject<USideViewCameraComponent>(TEXT("SideViewCameraRig")); CameraRig->SetupAttachment(RootComponent);`。跳跃（StartJump/EndJump）、移动（M1-029 的 ApplyPlanarMovement）、复位（ResetPosition）一行未动。**M0 旧相机逻辑去向：全部（弹簧臂参数 + 相机 FOV）移入本组件**；经 grep 确认旧逻辑只存在于 PrototypeCharacter.cpp/h，GameMode/HUD/SmokeRunner 无任何相机引用，**GameMode 无需改动**。
- `Source/UEMMO/Tests/SideCameraTests.cpp`（新建）：6 个无 World 纯函数自动化测试，前缀 `UEMMO.Tasks.M1_030.*`：AnchorZIgnoresJump、AnchorFollowsYDamping、RoomBoundsClamp、FacingDoesNotChangeYaw、GroundZFallback、SmoothFollowAxis。

## 已知限制

- 自动化与 smoke 均不模拟真实键盘事件：镜头手感（平滑速度 8/s、25% 阻尼的观感）属 H01 人工试玩范围，本报告不代签。
- GroundZ 使用 ECC_Visibility 通道向下单线检测（起点 = 角色 Z+50）：站立/跳跃场景可靠；若未来出现不阻挡 Visibility 的特殊地面（如 trigger 楼层）需换通道或 Object 检测。
- 锚点 Z 未做平滑（直接锁地面）：平地跳跃波动 0cm；上台阶/斜坡时镜头 Z 会逐帧跟随地面台阶跳变，若需要缓冲属后续任务。
- Y 阻尼参考 `ReferenceY` 在 BeginPlay 定格：按 R 复位后 Y 阻尼值瞬间回位（X 仍平滑），与 M0 复位即瞬移镜头的行为相近，未在本卡扩大处理。
- 偏离任务简报一处：简报写 SpringArm 头文件为 `GameFramework/SpringArm.h`，UE 5.8 实际为 `GameFramework/SpringArmComponent.h`（与现有 PrototypeCharacter.cpp 一致）；另 USTRUCT 暴露 BlueprintReadOnly 属性需 `BlueprintType` 标记，均已按引擎实际修正。
- 渲染截图为落地后采集，未含空中瞬间画面；空中稳定性由纯函数测试 + 每帧地面检测机制证明（见上）。
