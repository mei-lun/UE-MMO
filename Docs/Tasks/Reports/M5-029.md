## 验收对照

- **不同重力配置产生不同轨迹，同初速0重力等价直线**：`ZeroGravityMatchesLinear`——scale=0 时与直线策略同参数弹道逐点等价（加速度为 0，ComputeVelocity 恒返回 v0）；`GravityScaleTrendAndQuantum`——三 Y 泳道（偏移禁重叠）scale=0/1/2 同初速 10 步 1/60 推进，z(t) = z0 + vz·t + ½·(-980)·scale·t²（Verlet 解析精确），容差 0.1cm 只覆盖浮点累积，趋势 z2 < z1 < z0，并钉住 `World->GetGravityZ() == -980`（防测试世界重力被改后断言静默漂移）。
- **高速落地不穿地板，终止或爆炸事件一次**：`HighSpeedLandingNoTunnelSingleEvent`——高速下落单步大步长不穿透 5cm 薄地板，恰一次终止事件，落点球心 = 地板顶 + 半径（容差 3.0cm）且球底永不进入地板内部（不变式断言）；`HostileHitSubmittedExactlyOnce`——命中 Hostile 血量目标恰一次统一提交、扣血一次；`SelfPassThroughThenHostileHit`——发射者自体双保险穿过后续 Hostile 正常命中。
- **失效/卸载不留下运动回调；定量误差容限在报告记录**：`NoResidualMotionOnInvalidation`——失效后 `IsActive() == false`、`IsFinished() == true`、引擎参数面归零（Velocity/GravityScale/InitialSpeed/MaxSpeed）、销毁后再 advance 为 no-op；策略头/实现零委托零定时器零组件激活，生命周期归 027 的引擎 LifeSpan 与 BeginNextWorldEpoch（本卡不另做）。

## 定量误差容限（卡面要求记录）

- **Chaos 扫掠 contact-offset 膨胀 ~2.2cm**：夹具实测——球（半径 8cm）静止于 200×200×5 盒顶面时，球心停在 z=710.205，而精确接触位置为 708（地板顶 700 + 半径 8），即球底 702.205 悬于真实顶面上方 ~2.2cm。这是 Chaos 物理引擎对形状的 per-shape contact offset（sweep 查询面比几何面外扩），非策略缺陷；测试容差 3.0cm 覆盖之，并另设「球底不低于地板顶面」不变式断言确保方向正确（膨胀只向上、绝不陷入）。

## 集成决策（卡面授权范围内）

1. **只设 UE 参数 + 驱动引擎积分面，零手写物理**：策略不维护任何位置/速度状态副本，每步以 `ComputeVelocity`/`ComputeMoveDelta` 序列精确复刻引擎 TickComponent 积分序（MoveDelta 必须用 InitialVelocity——引擎语义如此），运动参数（InitialSpeed 必须清零防覆盖、MaxSpeed=0 不限速、ProjectileGravityScale 透传）全部走组件公开面。
2. **命中面完全复用 028 共享契约**：`ClassifyProjectileHitActor` fail-closed 分类、`FProjectileHitContext` 值快照、五元组统一提交、PierceCount 预算语义与直线策略逐字一致；差异仅在步方向随重力每步重取（直线为常向量）。
3. **寿命归 027**：本卡不实现超时（M5-027 已冻结引擎 LifeSpan + Pause 冻结语义），策略只负责运动与命中。
4. **AdvanceMotion 无世界/组件状态残留**：策略永不激活 ACombatProjectile 的组件、零 Timer/委托；失效（actor 销毁/生命周期终结）后 advance 为 no-op。
