  - 七个行级解析器（每个提供 JSON 值重载与 JSON 文本便捷重载）：`ParseDamageProfile`/`ParseAttackReaction`/`ParseTargetReaction`/`ParsePresentation`/`ParseWeaponDefinition`/`ParseAmmoType`/`ParseProjectileDefinition`。每个行对象执行严格 schema：字段集合精确封闭（未知字段点名拒绝）、全部字段必填、JSON 类型逐一核对（布尔不接受 1/0、整数不接受 2.5、数组元素逐个点名）、ID 走小写 `a-z0-9_` 1-64 语法、枚举词走 003/004 的 ParseControlPenetration/ParseWeaponFireMode/ParseProjectileMotion，随后必须通过对应 `ValidateDamageProfile`/`ValidateAttackReaction`/`ValidateTargetReaction`/`ValidateWeaponDefinition`/`ValidateAmmoType`/`ValidateProjectileDefinition`（NaN/负值/越界/非法组合全部拒绝）。任一问题收集完整列表以 `"; "` 连接；失败时 Out 结构重置为默认值，不发布半行。
