## 集成决策（卡面授权范围内）

1. **穿透集合按实体 id 记账（而非 Actor 指针）**：与 030 同构——只持值 id，命中时经 Identity seam 解析；集合成员是注册实体 id，天然覆盖同 Actor 多碰撞体（同一 Actor 解析同一 id）。Ledger 保持跨弹幂等权威，本弹集合只管「不重复提交、不浪费预算」两层语义。
2. **标签过滤落在 Category（注册表既有标签面）**：`FCombatEntityMetadata` 只有 Faction/Category 两个标签字段且属 010 冻结头——031 不得改公共头，故忽略标签集作用于 Category（信息性分类标签，例如 "prop" 不应被玩家弹丸伤害）；过滤仅作用于将被伤害的 Hostile 命中（友军仍按其 filter 位走），被过滤实体不入命中集合、不扣次。
3. **「世界障碍始终阻断」以 Begin 拒绝 + 运行期硬终止双面钉死**：`bUnregisteredActorsBlockShot=false` 的 context 对穿透弹是非法组合（拒绝绑定）；运行期 Unregistered 分类一律 `FinishBlocked()` 终止（无提交无扣次）。02x 系列的 context 位在策略面收窄为本策略保证。
4. **爆炸+穿透拒绝在策略缝再强化**：004 已在定义级拒绝该组合；策略 `Configure` 接收接线方解析的 `ExplosionRadiusCm`（策略不读目录），Begin 对「半径>0 且预算>0」拒绝——接线层无论如何解析定义，穿透策略都不会持有会多次引爆的弹。爆炸本身的行为（032 谱系）不在本卡。
5. **拒绝面 fail-closed + 合法对照录红模式**：所有 Begin/Configure 拒绝探针都伴随一条合法对照断言（合法爆炸配置可绑定、Configure 零半径可接受、合法 context 可 Begin），桩期全拒绝即红——延续 030 确立的模式供 032 参照。
