## 已知限制

- **纯逻辑类，尚无 World 挂载**：本卡文件范围只有 Registry/Ledger 五个文件，二者为普通 C++ 类，谁按 World 持有实例（WorldSubsystem/组件桥）归集成任务（如 012）实现；`BindRegistry` 是当前唯一的关联方式。
- **id 空间按 Epoch 重启**：重建后从 1 重新分配；跨重建持有 (Epoch,Id) 对的调用方必须携带 Epoch，旧代际请求由显式 StaleEpoch 检查拦截。代际内 id 单调不回收。
- **注销不清理账本**：`UnregisterEntity` 后该实体已记录的键保留至 EndShot/Reset（新请求以 UnknownSource/UnknownTarget 拒绝）；已死亡实体的未结束实例仅在 EndShot/Reset 时释放容量。墓碑按 Epoch 内分配量上限累计（不占容量、不持键），Reset 清空。
- **容量口径**：容量限定活跃 Shot 实例数（默认 256），单实例键量由弹丸数×目标数上界约束；`DeriveCombatEventId` 为 64 位 FNV-1a，理论碰撞可能但不作为安全依据（去重面是键本身）。
- `RegistryRegisterResolve` 的裸瞬态 AActor 仅用于弱引用 resolve 路径，理论上存在 GC 干扰窗口（沿用 M3-023 先例，实践无碍）。
