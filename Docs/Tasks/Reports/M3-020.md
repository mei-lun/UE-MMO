### 已知限制

- "新进程"为模拟：新 `UGameInstance` + 新 `UProfileSaveService` + StartupLoad/RestoreFromSave（M3-015/016/017 既有模型），不是真实 OS 进程重启；自动化无法执行真重启。
- 地图开启为注入的计数模拟器（临时 World 无法真实 Level travel）；房间波次在临时 World 内真实推进。
- 掉落种子探测：起始掉落表对武器是概率掉落，用例经公开纯函数预览探测到武器种子后再真打该局（预览不消耗状态）；探测产生的 `StartRoom` 事件使 start 计数相对基线断言（本轮修正点）。
- 存储层为内存 `ISaveStorage`；真实 USaveGame 文件路径的读写由 M3-014 既有冒烟测试覆盖，本套件不重复。
- 事件序列 JSON 的时间戳为注入场景时钟值（波次阶段 0→2.05s 推进；结算/穿戴阶段无时钟推进故同刻记录），顺序可靠、绝对时刻不表示墙钟。
