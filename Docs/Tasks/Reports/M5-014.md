| 旧路径（硬编码位置） | 旧行为 | M5-014 resolver 产出 |
|---|---|---|

| M1-025 Z 缩放（`EvaluateAirCombo` 常量 1.0/0.7/拒绝，攻击侧） | launcher 每浮空周期两次缩放 | `ResolveLaunchZScale(TargetPolicy, LaunchIndex)` 读 `FTargetReaction.MaxLaunchesPerAirCycle/LaunchZScales`（默认 2/{1.0,0.7}，逐值一致）；参与性 `bPerCycleLaunchScaling` 仍由组件侧决定（仅 launcher） |
| 冲量方向 `FVector(Facing*KnockbackSpeed, 0, bLaunch ? launch : 0)` | X 镜像、Y=0、Z=采纳浮空 | `Request.ImpulseVelocity`（X 只镜像、Y 恒 0 不锁纵深、Z=采纳浮空）；执行时仍由统一入口 `Outcome.Control.bLaunch` 门控 |
| stun 转发（统一入口 bStagger → NotifyHitReceived） | 门控转发定义 HitStunSeconds | `Request.bStagger` + `Request.StunSeconds`（同一 M5-011 门计算）；转发路径未改 |
| 硬直 max 覆盖（M1-020 `max(remaining,new)`） | 不叠加 | `Request.StunOverride = EHitStunOverride::Max` 显式声明，仍由 `NotifyHitReceived` 唯一执行 |
| 攻击中断（`CancelCurrentAttack("HitStun")`，桥接命中即打断） | 伤害或控制命中打断在打攻击 | `Request.bInterruptAttack = bDamageApplies \|\| bControlAccepted`；执行仍走原 `CancelCurrentAttack("HitStun")` |
| 死亡优先 / 起身保护（统一入口 stage 1e/1f） | 死者与 landing recovery 整体拒绝 | `Request.bRefuseHit` + `RefuseReason(Death/GetUpProtection)`，事实由组件从唯一状态属主读取；统一入口同名门保留为第二道防线 |
| 免控（`bImmuneControl`/`bAllow*` 门） | 超级霸体：全额伤害零控制 | `Request.bControlAccepted`（独立结果面） |
| 免伤（M5-011 `bWasImmune`） | 恰好 0 伤，控制照常 | `Request.bDamageApplies`（独立结果面，与免控不合并）；实际扣血永远以统一入口 `Outcome.DamageApplied` 为准 |
| 浮空计数（`bLauncherLaunchAllowed && Impulse.Z>0` → `RecordLauncherLaunch`） | 仅已施加的 launcher 浮空计数 | `Request.bLaunchAdmitted` + 同一 Z>0 条件；计数源 `M1_025_ResolveLauncherCycleCount` 未改（M5-015 统一） |

### 限制与后续

- 请求携带的 `KnockdownSeconds/RecoveringSeconds` 目前只是策略透传参数；
  `BeginLandingRecovery` 仍读 M1-026 常量（0.45/0.25），M5-016 参数化触发判定与时长。
- 韧性（PoiseMax>0）只产出 `bControlFacesPoiseThreshold` 事实，消耗池是有状态行为
  （M5-015 落地）；本卡 PoiseMax>0 的策略不阻止控制，与默认行为一致。
- `FAttackReaction` 为组件级单值注入，不按 AttackId 映射；BypassPoise 与 None 在
  无韧性目标上请求完全一致（穿透的可观测差异随韧性池在 M5-015 出现）。逐攻击映射
  随 M5-020A 数据接线。
- 目标侧浮空计数源仍是 `M1_025_ResolveLauncherCycleCount`（仅 ATrainingEnemy，其余
  目标读 0），M5-015 统一目标侧计数表面。
- resolver 的状态拒绝使该目标提前一步跳过统一入口提交；统一入口的同名门（死亡/
  起身保护）对一切到达的请求仍生效，可观测行为逐字节不变（无 ledger、无扣血、无事件）。
- registry/ledger 保持"每攻击者组件一份"（M5-013 限制，本卡未动）。
