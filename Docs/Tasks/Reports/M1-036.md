## 预览取证方式（真实渲染，非推测）

1. **取证脚本**（存于证据目录，不进 Scripts/）：`preview_editor2.py` +
   `bootstrap_editor.py`。用 GUI 编辑器进程
   `UnrealEditor.exe UEMMO.uproject -ExecCmds="py exec(...)"` 启动，编辑器就绪后脚本：
   - 在内存中加载 `/Game/UEMMO/Maps/L_PrototypeArena`（**不保存**，git 零残留）；
   - 每招生成临时 `SkeletalMeshActor`（SKM_Manny_Simple），单节点播放该招源动画，
     冻结播放速率后把 `saved_position`/`set_position` 定格到目标源片段时间，
     再生成临时 `SceneCapture2D` 渲染到 RenderTarget 并 `export_render_target` 导出 PNG；
   - 同时在新进程内核对四份 Montage 的槽段引用与 JSON `animation_path` 一致，
     并导出动画元数据（时长、rate_scale、根运动标志）到 `attack-preview-report2.json`；
   - 全部完成后 `QUIT_EDITOR` 自行退出。
2. **帧→源片段时间映射**：`源片段时间 = 逻辑帧 × clip_end_seconds / duration_frames`
   （等价于逻辑时间除以 M1-032 的 `ComputeMontagePlayRate`）。每招取生效窗首帧与末帧
   （[start, end) 半开窗，故末帧取 end-1），light_01 额外取 t=0.05s 做校准帧。
3. **迭代说明（如实记录）**：第一轮（commandlet `-run=pythonscript`）SceneCapture 只渲染
   清屏色（commandlet 编辑器 World 无渲染 Scene）、`export_render_target` 也不落盘，
   且 `set_position` 未生效（同一招两帧导出图像像素级相同，已用 IDAT 哈希证实）。
   第二轮改为 GUI 编辑器执行并先冻结速率、经 `saved_position` 设位，18 张导出图
   **逐张像素内容唯一**（IDAT MD5 18/18 不重复），校准帧 t=0.05 与生效帧姿态明显不同，
   证明定格时间真实生效。第一轮 16 张 PNG 与脚本保留在同目录作迭代证据
   （`preview_attack_animations.py`、`pose_*.png`、`attack-preview-report.json`）。
4. **目击记录**：第二轮图像已逐张人工目击（本 Agent 实际打开查看）：
   light_01（front cal/active_start、side active_last）、light_02（side 起止两帧、front active_start）、
   launcher（front 起止两帧、side 起止两帧）、aerial_01（side 起止两帧、front active_start）。
   该取证是**定格单帧观察，不是运行时连招目击**；蒙太奇连播观感仍需 H01 用户试玩。

## 替代评估与不替换原因

1. **已入库 97 条动画内无替代候选**（`Artifacts/animation-inventory.json` 全量分组核对）：
   Unarmed/Attack 仅 MM_Attack_01/02/03/ChargedAttack 四条，其余为移位（Jog/Walk/Pistol/Rifle）、
   跳跃（Jump/Dash/WallJump/Fall/Land）、受击（Rifle/HitReact，带武器姿态）与死亡。
   没有第二条"上挑"或"空中攻击"候选可互换；MM_Dash（0.967s）与 MM_WallJump（0.467s）
   是位移动作，观感适配更差。launcher 与 aerial_01 的当前映射已是库内最优。
2. **原作者免费渠道只记录、不下载**：按 Docs/03 第 3 节，候选为 Quaternius
   Universal Animation Library / QAL 2（免费层，Epic Marketplace 无对应徒手连招包）。
   本卡尝试仅读取 itch.io 产品页核对免费层清单（**未下载任何文件**），
   页面连接超时（与此前 AcquireResources 的下载超时一致），故
   **免费层是否包含专用上挑/空中动作 = 未验证**，不得写成可用候选。
3. **未替换的明确原因**：库内无更优候选 + 免费层候选无法验证 + 现有占位可完成
   机制验证（M1-008 起 launcher/aerial_01 即 `placeholder_animation=true`）。
   替换决策留给用户：接受占位进入 H01 试玩，或后续网络可用时按 Docs/03 第 6 节
   流程（许可→SHA256→独立命名空间导入→重载→截图）引入专用素材。
