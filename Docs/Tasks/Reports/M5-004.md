### 实际修改

- 新建 `Source/UEMMO/Weapons/WeaponTypes.h`：
  - `EWeaponFireMode : uint8 { Melee=0, Hitscan=1, Projectile=2 }`（封闭三值）＋ `IsValidWeaponFireMode` / `ParseWeaponFireMode`（大小写不敏感，空串/未知文本拒绝）。
  - `FWeaponDefinition`：WeaponId（FName）、FireMode、DamageProfileId、AmmoId、MagazineSize、FireRateRpm（发/分钟）、BurstCount、PelletCount、SpreadDegrees（度）、RangeCm（cm）、ProjectileId、MeleeAttackIds（数组）。所有字段带单位与默认值注释。
  - 有界常量：`MaxWeaponPelletCount=32`、`MaxWeaponBurstCount=12`、`MaxWeaponMagazineSize=999`、`MaxWeaponSpreadDegrees=45`、`MaxWeaponFireRateRpm=3000`、`MaxWeaponRangeCm=1000000`。
  - `GetLegacyMeleeAttackIds()`：完整旧四招 {light_01, light_02, launcher, aerial_01}。
  - `IsValidDefinitionIdText`：业务 ID 小写 `a-z0-9_`、1-64 字符（设计 §4）。
  - `ValidateWeaponDefinition`：收集全部独立问题并以 `"; "` 连接、逐条点名字段。按模式规则：
    - melee：AmmoId/ProjectileId 必须为空；MagazineSize=0、FireRateRpm=0、SpreadDegrees=0、RangeCm=0、BurstCount=1、PelletCount=1；DamageProfileId 必填；MeleeAttackIds 必须恰为旧四招完整集合（顺序无关、不许重复/缺失/未知）；攻击节奏与命中几何仍归旧攻击定义。
    - hitscan：AmmoId/DamageProfileId 必填；ProjectileId 必须为空（射线不生成 Actor，设计 §4）；MagazineSize≥1、FireRateRpm>0、RangeCm>0；MeleeAttackIds 必须为空。
    - projectile：AmmoId/ProjectileId 必填；DamageProfileId 必须为空（伤害权威在被引用的 FProjectileDefinition，避免双权威）；RangeCm 必须为 0（射程权威在弹丸 lifetime×speed）；其余同 hitscan。
- 新建 `Source/UEMMO/Weapons/AmmoTypes.h`：`FAmmoType { AmmoId, MaxReserve, MagazineSize }` ＋ `ValidateAmmoType`（ID 同上；MaxReserve 0..99999，0 合法；MagazineSize 1..999）。常量 `MaxAmmoReserve=99999`、`MaxAmmoMagazineSize=999`。
- 新建 `Source/UEMMO/Projectiles/ProjectileTypes.h`：
  - `EProjectileMotion : uint8 { Straight=0, Parabolic=1, Homing=2 }` ＋ `IsValidProjectileMotion` / `ParseProjectileMotion`。
  - `FProjectileDefinition`：ProjectileId、Motion、SpeedCmS（cm/s）、LifetimeS（秒，Pause 冻结的 World 时钟口径）、DamageProfileId、PierceCount、ExplosionRadiusCm（cm，0=无爆炸）、ExplosionDamageProfileId、HomingTurnRateDegS（度/秒）。
  - 有界常量：`MaxProjectileSpeedCmS=100000`、`MaxProjectileLifetimeS=60`、`MaxProjectilePierceCount=32`、`MaxProjectileExplosionRadiusCm=10000`、`MaxHomingTurnRateDegS=720`。
  - `ValidateProjectileDefinition`：速度/时长必须有限且严格为正；爆炸语义为 radius>0 ⇔ ExplosionDamageProfileId 非空，且 radius>0 时 PierceCount 必须为 0（首版爆炸禁止同时穿透，一个弹丸不得多次爆炸）；homing 必须 HomingTurnRateDegS>0，非 homing 必须为 0（未知 motion 不归入 non-homing，单独报错）；PierceCount 0..32。
- 新建 `Data/CombatSystem/weapons.json`（8 行）：`weapon_training_sword`（melee+旧四招）、`weapon_hitscan_sample`（单发射线）、`weapon_burst_sample`（burst_count=3 点射）、`weapon_pellet_sample`（pellet_count=5 多弹丸+8° 散布）、`weapon_projectile_sample`（直线弹）、`weapon_parabolic_sample`（抛物线）、`weapon_homing_sample`（追踪）、`weapon_explosive_sample`（爆炸，经 rocket_explosive）。每行显式写出全部 12 个字段（空串/0/1 表示"按模式必空/必零"），表结构 schema_version=1/table/rows。
- 新建 `Data/CombatSystem/ammo_types.json`（5 行）：ammo_cell/ammo_light/ammo_shell/ammo_missile/ammo_rocket。
- 新建 `Data/CombatSystem/projectiles.json`（5 行）：bullet_linear（直线）、bullet_piercing（穿透 2）、shell_parabolic（抛物线）、missile_homing（追踪 180°/s）、rocket_explosive（爆炸半径 300 cm + explosive_40，pierce=0）。
- 新建 `Data/CombatSystem/target_filters.json`：target_filters 表 2 行（filter_id/allowed_team_relations/required_tags/excluded_tags/block_world；首版 tag 数组为空——tags.json 由 002/006 落地，避免悬空 tag 引用）＋ `test_room` manifest 首版结构：`menu_entry`（"TestRoom"，与 M3-017 菜单入口文本同风格）、`map_path`（/Game/UEMMO/Maps/L_CombatRoom01，与 rooms.json 同路径口径）、`waves[]`（wave_index/layout_id/target_filter_id/reward_pool_id，target_filter_id 引用本表行）、`vehicle_spawns: []`（首版为空；037 扩展列表并校验其字段，本卡不硬编码内容列表）。
