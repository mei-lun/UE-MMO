## 已知限制

- `FPendingRewardSaveEntry` 为 FPendingReward 的值结构镜像：RewardService.h 属只读复用文件，FPendingReward/FItemInstance 是非反射纯值结构，无法直接作 UPROPERTY；物品以 M3-001 快照字符串携带（卡面许可的两种形态之一）。同理 EItemSlot 未反射，槽位以 uint8 携带并在加载时按闭合枚举校验。
- 派生属性（MaxHP/Attack/Defense）不入档：加载后按等级公式重建（装备前基线行），装备加成由玩法层（M3-005/M3-010）在重新装备后重算，存档永不固化派生值。
- 浮点属性往返经由 M3-001 ToStringSnapshot（引擎 SanitizeFloat，%f 六位小数去尾零）；本测试取二进制精确可表示值保证逐位一致，超出六位小数精度的任意浮点不保证逐位往返——该精度行为继承自 M3-001 既有格式，非本卡引入。
- MasterVolume 为设置占位：ToSaveGame 恒写默认 1.0f，尚无设置域读写（已在头文件注释与本报告声明）。
- ToSaveGame 按设计信任调用方输入不做校验；不一致的输入会在加载侧被拒绝并暴露。AppliedSettlementIds 数组中的手造重复 ID 在加载时按集合语义收敛（不拒绝）。
- 本卡不触磁盘：未知 schema 下"保留原文件"在对象层验证（SaveGame 不被改写），文件级保护由 M3-014 的槽服务落实。
- CheckTaskBoard 对 M3-009/010/011 报告的报错为基线既有问题，超出本卡文件范围，未处理。
