## 目的

按接口约定实现 `ECombatInput`、`FBufferedCombatInput`、`FCombatInputBuffer`：容量 4、会话内 Sequence 严格递增（拒绝重复/回退）、满员丢最早一条、按入队顺序一次性消费指定动作。本卡不实现时间过期；`PruneExpired`/带寿命的 `Consume` 由 M1-004 在同一类型上扩展（接口约定："首次定义 M1-003；过期扩展 M1-004"）。

## 实际修改

- `Source/UEMMO/Combat/CombatInputBuffer.h`：三个类型 + `FCombatInputBuffer`（Push/ConsumeFirst/Size/Reset），私有 `Capacity=4`、`Entries` 数组、`LastAcceptedSequence`。只依赖 Core。
- `Source/UEMMO/Combat/CombatInputBuffer.cpp`：实现。Push 拒绝 `Sequence <= LastAcceptedSequence`；满 4 条先 `RemoveAt(0)` 再追加；ConsumeFirst 按入队顺序找第一个匹配动作，删除并返回 true，未命中返回 false 且不动其他条目；Reset 清空并复位 Sequence 会话基线。
- `Source/UEMMO/Tests/InputBufferTests.cpp`：5 个测试（`UEMMO.Tasks.M1_003.EmptyQueue / FifoOrder / ActionMatchKeepsOrder / CapacityOverflow / SingleConsumptionAndDuplicates`），无 Actor/World 依赖。
