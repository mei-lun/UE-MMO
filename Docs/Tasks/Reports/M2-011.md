### 已知限制

- LeaveRoom 按卡面只清弱引用，不销毁、不停驻本 run 登记的敌人 Actor：地图卸载负责 Actor 销毁，M2-010 的 DestroyRunEnemyActors 仍是重试清理的销毁通道。
- LeaveRoom 目前尚无生产调用方（M2-009 的 RoomExit 仍只发 BeginExit 信号，真实退出入口是 M2-012 的 UI/服务接线）；本卡交付会话层流程并锁定行为。
- WaveSpawner 世界防护为纵深防御：可确定测试的是 EndPlay 后（bIsTearingDown）的迟到出生路径；"World 被替换但未拆除"分支（`World != SpawnWorldPtr.Get()`）与死亡路径的 World 校验叠加在既有 run-id/状态过滤之下，无法在不人为换绑 World 的前提下单独触发，故未设独立用例（避免机械补测试）。
- StartRoom 同时接受 M2-006 BeginExit 产生的 Exiting 状态（同一状态、同一清理假设），这是切回房间流程的既定语义而非漏洞。
- 会话时钟注入在测试里跨 run 重置锚点（各波 spawner 各自锚定首次 UpdateWave），不依赖注入单调性；生产驱动按帧单调注入。
