## 目的

按接口约定第 4 节建立组件级攻击生命周期 `UCombatComponent`：`TryStartAttack(FName, int32 Facing)` 从空闲开始一次攻击并铸造新的会话内递增 `AttackInstanceId`（uint64，从 1 起），`TickCombat` 用 M1-004 的 `FCombatClock`（60Hz）推进逻辑帧，`light_01` 推满 26 步（Frame 到 DurationFrames-1=25）后结束并**恰好广播一次 Finished**，`ResetCombat` 立即拆解回 Free 且**不发 Finished**；`GetSnapshot` 输出 AttackId/InstanceId/Frame/Facing/ActionState/BufferSize，`CanAcceptMovement`/`CanTurn` 给 M1-013 消费。本卡只做生命周期：不接键盘、命中、动画或角色移动（命中属 M1-017+）。

## 设计决定

1. **Reset 语义：不发 Finished**。Reset 是拆解不是攻击结束，`OnFinished` 的"每完成实例恰一次"契约不被 Reset 污染；取消语义（`CancelCurrentAttack(FName Reason)`）留给后续任务按接口约定补位。Reset 同样**不重置 InstanceId 计数器**（验收要求 Reset 后再启动得不同 ID）、**不清死亡标志**（死亡属生命域，M1-027 统一 Reset 再收口）、不清缺失 ID 诊断集（目录未变）。
2. **委托形式：原生多播**（`DECLARE_MULTICAST_DELEGATE_TwoParams`），仿 HealthComponent `FOnDied`；参数 `(FName AttackId, uint64 InstanceId)`，Started/Finished 同形。其他组件不得另维护一套攻击计时（接口约定 §4）。
3. **SetDead 为最小显式钩子**：仅置位/清位，令 TryStartAttack 拒绝新开始（死亡最高优先级的第一步）；**不中断已在飞行的攻击、不接 HealthComponent**（M1-016/M1-019 接线并负责死亡打断）。`CanAcceptMovement`/`CanTurn` 额外纳入 `!bDead`：死亡优先级高于 Free 判定，属接口约定 §4"死亡最高优先级"的最小落实（M1-013 消费时无需再补）。
4. **目录注入**：`InitializeFromCatalog(UAttackCatalog*)` 显式注入 + `UPROPERTY(Transient)` 持引用；构造零 ini 读取，测试注入无 World 依赖，游戏启动接线留后续任务。
5. **Finished 先清状态后广播**：回调内看到的快照已是 Free，允许在 Finished 回调里直接链下一击。
6. **bFrozen 透传**：`TickCombat` 签名保持接口约定原文 `(float DeltaSeconds)`，冻结以成员 `bClockFrozen`（默认 false）+ `SetClockFrozen` 提供，逐调用透传给 `FCombatClock::Advance`；本卡测试恒 false，另有 `FrozenClockPausesFrameAdvance` 证明透传有效（冻结掉帧、不追帧语义由时钟本身保证）。

## 已知限制

1. **未接游戏启动流程与角色**：无键盘输入、无命中、无动画、无 Character 挂接；组件由测试或后续任务显式构造/注入目录，`TickCombat` 需外部每帧调用。
2. **死亡不中断进行中攻击**：`SetDead(true)` 只拒绝新开始；死亡打断/与 HealthComponent 联动属 M1-016/M1-019。死亡标志也不被本卡 Reset 清除（M1-027 统一 Reset 收口）。
3. **输入缓存恒空**：`FCombatInputBuffer` 成员与 BufferSize 字段保留，`QueueInput` 未实现（接口约定 §4 的取消/队列扩展位留后续任务）；`CancelCurrentAttack`、HitStun 等状态未实现（本卡子集）。
4. **InstanceId 会话内唯一**：uint64 从 1 单调递增，不跨进程/不序列化；两角色本地实例 ID 可能碰撞，命中去重需按接口约定 §5 另加攻击者实例来源（M1-019）。
5. `CanAcceptMovement`/`CanTurn` 为快照驱动最小实现（Free 且存活），后续 HitStun/Knockdown 状态加入后自动收窄为非 Free 即拒绝，无需改这两处逻辑。
6. 本卡按协调者要求未登记/修改 TASKS.md、HANDOFF.md 与 Docs/Tasks/Handoffs/（由协调者统一维护）；Artifacts 不入 git。
