### 已知限制

- **奖励行永久隐藏**：M2 无装备/奖励数据，`RewardText` 恒空（两态一致）；真实奖励内容属 M3 结算任务（M3-018 已把 M2-012 列为依赖）。

- **游戏内 Session 时钟无驱动**：生产代码尚无 `SetSessionClockSeconds` 注入者（M2-008 明确由后续 frame driver 任务接线），因此游戏内 run 的 ElapsedSeconds 当前显示 0.0；波次出生同样依赖注入（M2-009/010 报告已记录同一限制）。截图中的 "Time 0.0 s Kills 0" 是 Session 实测真值，非伪造。

- **真实键盘/鼠标手感**：InputMode 切换经 -game 日志与状态标志验证；物理键注入不可行，手感归 H01。
