## 目的

按接口约定第 7 节实现 `URoomSessionSubsystem : UWorldSubsystem`：管理单局生命周期 Idle/Running/Cleared/Failed/Exiting，生成局内唯一 RunId、进程级唯一 SettlementId 和可复现 Seed；开始/结束事件每局只发一次；终态首个胜出、结局不可覆盖；旧回调（终局后的击杀通知）幂等忽略；World 销毁路径清理本 World 注册的委托与状态。本卡不执行波次刷怪（M2-007）、不保存背包、不实现退出流程本体（M2-011）。

## 关键实现语义

- **状态机**：StartRoom 仅 Idle 可用（null 定义拒绝；Running/Cleared/Failed/Exiting 一律拒绝且不触碰当前 RunId/Seed/RoomId）；MarkCleared/FailRun 仅 Running 可用（共用 `EndRun` 体，bCleared 决定结局，首个终态胜出，后到的另一结局请求被拒并写诊断日志）；BeginExit 自任意非 Exiting 状态进入 Exiting（Running 中途退出保留局内簿记、不发 OnRunEnded，退出流程本体归 M2-011）；ResetToIdle 仅 Cleared/Failed/Exiting 可用（Running 必须先终局或退出），清空全部局内簿记。
- **身份生成**：RunId 为会话内递增 uint64（实例计数器，Deinitialize 随实例归零）；SettlementId 为进程全局计数器（文件内匿名命名空间计数器，跨 World/跨局永不重复，刻意不随 Deinitialize 归零——独立验收第 3 条）；Seed = RunId 的 Knuth 乘法散列折叠到正 int32 区间（`Seed = int32((RunId * 0x9E3779B97F4A7C15) >> 33 & 0x7FFFFFFF)`），固定公式、零随机，M2-007 掉落/刷怪可直接按 RunId 复现同一 Seed。
- **事件幂等**：OnRunStarted 每局恰一次；OnRunEnded 在首个终态转移时恰一次，重复 MarkCleared/Fail 不再广播、不覆盖 `LastResult`。
- **时钟**：`SetSessionClockSeconds` 显式注入（与 CombatComponent 的 SetInputClockSeconds 同风格，非有限值忽略），ElapsedSeconds = 终局注入值 − StartRoom 注入值；任何路径不读墙钟。
- **EndPlay 清理**：`Deinitialize()` 清空两个委托（Clear）并重置全部状态；引擎在 `UWorld::CleanupWorld → SubsystemCollection.Deinitialize()` 调用它（已核对 5.8 引擎源码调用链 `UWorld::DestroyWorld → CleanupWorld`）。

## 已知限制与偏离

- **WaveIndex / AliveIds / PendingSpawns 未实现**：接口约定第 7 节列出它们，但本卡明确"不执行波次刷怪（M2-007）"，且卡面实现要求未列这三者；留给 M2-007 按其语义添加，避免本卡发明无消费者的占位字段。
- **Seed 策略**：RunId 派生（Knuth 乘法散列），非引擎随机流；报告如实记录，M2-007 若需更强分布可在此公式上演进，但同 RunId 同 Seed 的可复现承诺不变。
- **FRoomResult/ERoomSessionState 为纯 C++ 类型**（未加 USTRUCT/UENUM 与 BP 元数据）：本卡消费者全部是 C++；后续任务如需蓝图访问再加 UHT 标注（纯增量改动）。
- **Running 直接 ResetToIdle 被拒**：中途放弃需走 BeginExit→(M2-011 流程)；测试 7/8 钉死该语义。
- 测试通过临时 World 驱动真实子系统；自动化不覆盖真实键盘试玩，本卡无画面改动（无需 Test -Render）。
- EngineFilter/EditorContext/ClientContext 标志与既有套件一致；测试产生的临时 World 由引擎 GC 回收，与既有测试做法相同。
