## 实际结果

按用户明确授权，把 279 个网格（266 个主包、13 个 Unity 内置）适配为 UE 5.8.3 Static Mesh，输出 `/Game/UEMMO/Imported/DNFM130_5_8`。137 个来源材质、39 个可解析纹理、2 个辅助材质及展示关卡 `Maps/L_DNFM_ResourceGallery` 已落盘。几何与配套材质可以拖入项目关卡使用；未把该目录声明为完整原版场景、骨骼角色或可播放粒子系统。

## 缺口与诚实边界

1. **154 个网格默认材质引用缺失源纹理**，保留中性占位与 `MISSING_TEXTURE` Actor 标记。公会 36 个真实材质的底色仍指向缺失 CAB `6af7f14628a7155654ed172c566e3677`；8,445 包和 APK 外层 223 个 Unity 源均未找到精确对应。这是提供首包的资源边界，不能靠 OBJ/FBX 转换补出原图。
2. 自定义 Unity Shader 在 UE 做可追溯近似；未实现 `_MaskTex`、`_DistortionTex`、`_GradientTex`、`_MainTex2`、`_DissolveTex` 等特殊输入在材质 metadata 和报告逐项列出。颜色/透明/UV/基本纹理已接；不承诺溶解、描边、扭曲与原游戏一致。
3. 1 Unity 数值单位按1米换算；源 prefab 世界层级未重建。展示缩放用于查看，不改变网格资产的转换数值。
4. 源无完整蒙皮角色；Spine、音频、动画曲线/粒子仿真不属本轮3D静态素材适配。所有原始导出仍在 DNFM 工作目录。
5. 内容、原始 FBX和中间 manifest 本机保留，不推送远程。后续精确外观恢复需要缺失纹理包及对应着色器行为证据。
