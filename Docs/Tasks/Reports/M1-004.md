## 目的

在 M1-003 的 `FCombatInputBuffer` 上扩展时间过期与复位语义（不新建类型）：`PruneExpired(Now, Lifetime = 0.150)` 剔除过期条目，`Consume(Action, Now, Lifetime, Out)` 先清理再消费，`Push` 拒绝非有限时间。过期定义 `Now - PressedAt > Lifetime`（严格大于，恰好 0.150 秒仍可用）；`PruneExpired` 同时剔除 `PressedAt` 非有限或明显未来（`PressedAt > Now`）的条目且保持有效条目顺序。所有时间来自调用方显式传入的单调输入游戏时钟，实现内部不读任何系统墙钟。`Reset` 行为 M1-003 已实现（清队列 + 序号水位），本卡未改动，仅以测试锁定。

## 实际修改

- `Source/UEMMO/Combat/CombatInputBuffer.h`：声明 `PruneExpired(double Now, double Lifetime = 0.150)` 与 `Consume(ECombatInput Action, double Now, double Lifetime, FBufferedCombatInput& Out)`（签名按接口约定第 2 节）；类注释补充"时间全部来自显式单调输入时钟"。
- `Source/UEMMO/Combat/CombatInputBuffer.cpp`：
  - `Push`：最先校验 `!FMath::IsFinite(Input.PressedAt)` 直接拒绝返回 false——不入队、不推进 `LastAcceptedSequence` 水位（后验：拒绝 NaN 后同序号仍可接受）。
  - `PruneExpired`：倒序遍历（保证幸存条目相对顺序不变），剔除条件为三选一：`PressedAt` 非有限、`PressedAt > Now`、`(Now - PressedAt) > Lifetime`。
  - `Consume`：等价 `PruneExpired(Now, Lifetime)` 后调用 M1-003 的 `ConsumeFirst`。
  - 显式包含 `Math/UnrealMathUtility.h` 以获得 `FMath::IsFinite(double)`。
- `Source/UEMMO/Tests/InputBufferTests.cpp`：追加 6 个测试（前缀 `UEMMO.Tasks.M1_004.*`）：`ExpiryBoundary / MixedActionPrune / NonFiniteAndFuture / ConsumePrunesThenConsumes / DefaultLifetime / ResetStartsNewSession`，全部使用显式时间参数（`MakeTimedInput`），不读系统时钟。

## 已知限制

- 停顿语义未接入：Pause/本角色 HitStop 期间时钟不推进、停顿期间仍收输入，由 M1-033 在调用侧接入（接口约定第 2 节）；本卡实现只消费显式传入的 `Now`。
- `Consume` 的 `Lifetime` 参数按接口约定签名无默认值；默认 0.150 只存在于 `PruneExpired` 的声明上。
- `Push` 无法判定"未来时间"（需要 `Now`），只拒绝非有限时间；未来时间戳允许入队、由 `PruneExpired`/`Consume` 按传入 `Now` 剔除——与卡面"PruneExpired 还要剔除 PressedAt > Now"一致。
- `Now`/`Lifetime` 参数本身为非有限值时行为未定义（NaN 参与比较恒 false，此时只清理非有限 `PressedAt` 条目）；接口约定未要求，实现未特判。
- 自动化测试验证纯数据结构逻辑；真实按键到 `Push` 的接线属于后续任务。
