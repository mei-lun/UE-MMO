## 集成决策（卡面授权范围内）

1. **策略类为唯一运动推进者**：每 tick 恰一次 `AdvanceMotion`，底层用 UE 运动组件 `MoveUpdatedComponent` 的 body-radius 整步 sweep——任何 dt 都是一整步一次扫掠，从机制上排除薄墙隧穿（非分帧采样）；pass-through 采用「瞬移过体 + 剩余距离续段」内部分段（每 tick 最多 8 段，`MaxProjectileSegmentsPerAdvance`）。
2. **pass-through 走廊限制（如实记录）**：单次推进内瞬移续段的走廊里，位于越体落点之后、剩余距离之内的新阻挡体不再被检测（per-advance 一次扫掠 + 显式瞬移的固有边界，头文件注释与实现注释均已标注）；下一 tick 从新位置重新起扫，恢复全检测。
3. **自体双保险**：Begin 把 SourceActor 加入 Body 移动忽略表（UE ignore list）+ 分类面 identity-based Self 判定（弱引用或 resolved id 双通道），枪口起点与路径重叠均不自挡不自伤。
4. **投射物碰撞语义**：027 的全 ECR_Ignore 是生命周期阶段默认；028 补 Pawn/WorldStatic Block（卡面文件范围授权），投射物之间保持互不撞（WorldDynamic 对 WorldDynamic 双 Ignore）。
5. **028 冻结接口，029..032 仅提供策略**：`IProjectileMotionPolicy` 三方法 + `FProjectileHitContext`/`ClassifyProjectileHitActor` 共享面即 029（抛物线）/030（追踪）等后继策略的唯一接入点；生产接线（谁调 Begin/AdvanceMotion、谁构造 HitContext）归 029..032/033 谱系。
