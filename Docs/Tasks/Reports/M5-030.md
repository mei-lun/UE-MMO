## 集成决策（卡面授权范围内）

1. **目标只持实体 id（Registry/Filter 选择的策略面）**：BindTarget 仅值登记 id；合法性（已注册/有 actor/非友军）在 Begin 用 Context.Registry 校验；每步 advance 重解析弱引用。策略零裸地址、零 Ownership——目标销毁/注销/换世界天然被下一次重解析捕获（「立即解除引用」）。
2. **有界转向导向 + 引擎积分（非引擎 homing 参数面）**：引擎 `bIsHomingProjectile` 是加速度语义（HomingAccelerationMagnitude 直指目标，速度漂移、曲率不随角速度单调），无法表达 004 的 `HomingTurnRateDegS`（deg/s 角速度语义）；故策略手写「方向导向」（guidance，非位置积分——位移推进仍全走 ComputeVelocity/ComputeMoveDelta 引擎面 + 028 扫掠），速度恒定、每步转角 ≤ 配置率，曲率是配置的确定函数。
3. **Destroy 动作 = 终止运动（IsFinished）**：策略不销毁 actor——actor 回收归 027 生命周期面（LifeSpan/BeginNextWorldEpoch）；「销毁」语义在策略面内即立即停止推进，调用方（033 接线）据 IsFinished 回收。
4. **丢失后零重搜**：解除引用后不再查询任何实体；测试以「场外注册诱饵靶永不命中 + 丢失切向逐步精确直线」作行为证据。
5. **拒绝面 fail-closed**：TurnRate 未配置（0）或非法、目标未绑定/未注册/无 actor/同 faction 一律拒绝 Begin（弹零副作用）；Invalid id 连 BindTarget 都拒绝。
