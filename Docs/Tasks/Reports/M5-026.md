## 集成决策（卡面授权范围内）

1. **Actor→Id 反查注入 seam**：010 注册表无 Actor→EntityId 面（只有 id→Actor 的 ResolveEntity），卡面又禁改公共服务——新增 `IHitscanTargetIdentity` 由调用方注入（测试夹具自记 id 映射；生产接线 027/033 用其挂载的注册设施实现）。这是本卡唯一的非公共新接口。
2. **友军穿透语义**：`bFriendliesBlockShot=false` 时友军不挡弹且不被伤害（applier SameFaction 兜底）；`bUnregisteredActorsBlockShot` 让墙/环境体默认挡弹——trace 只见带查询几何的 actor，WorldStatic 墙也走该面。
3. **TargetReaction 读目标自身策略**：命中装配时从目标 `UCombatComponent::GetTargetReactionPolicy()` 取（与 013..017 生产桥接同源）；无 combat 组件取默认 reaction，死亡抗性/免疫/门全部沿用 012 语义。
4. **多段 trace 手动排序**：`LineTraceMultiByObjectType` 结果不保证有序，按 `FHitResult::Distance` 排序后"最近候选先决策"，保证穿透/阻挡判定确定性。
5. **方向不归一化**：pellet 方向按 025 产出契约视为单位向量直通（拒绝仅查非有限/零向量），End = Origin + Direction·RangeCm；归一化责任在调用方，语义与 025 的"单位方向"产出一致。
