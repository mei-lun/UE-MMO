## 用户反馈与取证

用户：**"窗口不应该默认全屏，应该适配一下原始的资源大小的窗口"**。取证：DNFM 源视频资源（assets_video_*.mp4，208 个）的 tkhd 轨道头实测帧尺寸 **1280x720**——即游戏渲染/设计分辨率（UE 侧全部测试用例的 -ResX=1280 -ResY=720 与之一致）。

## 修复

- `Config/DefaultGameUserSettings.ini`（新增）：`bUseFullscreenMode=False` + `LastUserConfirmedResolutionSizeX/Y=1280/720` + `PreferredFullscreenMode=0`——UE 标准的打包默认窗口化通道。
- 重打包（PKG exit=0）+ 存档恢复；包内 boot 日志实证：`r.setres:1280x720`、`systemresolution.resx=1280 resy=720`。

- 用户试玩确认窗口观感（H 类，随 M8-022 一并）。

## 第二轮：用户反馈"没有看到变化"——Saved 存档覆盖 Default 与开机强制

用户复查无变化。根因：**包内 Saved/Config/Windows/GameUserSettings.ini（用户 11-02 起多次全屏运行写入）穿越了每次重打包**，其 `FullscreenMode=1` 覆盖 Default 的 CDO 种子（Default 只在无存档时生效——分辨率 1280x720 因此生效了，模式没有）。

修复：`APrototypeHUD::BeginPlay` 开机强制应用设计帧（SetFullscreenMode(Windowed)+SetScreenResolution(1280,720)+ApplySettings）——未来任何陈旧存档都无法复活全屏；游戏内尚无设置界面，此强制即契约（将来设置界面接入时改为门控）。

验证（第八版包+人为预埋陈旧全屏档 FullscreenMode=1/2560x1440）：开机后存档被改写为 **FullscreenMode=2（窗口化）+1280x720**，boot 日志 r.setres=1280x720 ✓。证据 `Artifacts/Tasks/M8-026/pkg8-verify/`。
