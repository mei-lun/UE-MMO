## 实际修改

- **新增 `Source/UEMMO/Dungeon/DungeonTypes.h`**：FDungeonSequenceRow（DungeonId/RoomIds/XPReward）、
  FDungeonRunState（DungeonId/CharacterId/RoomIndex/RunGeneration/SettlementToken/SavedHP/
  SavedMP/CooldownRemainders/ConfigRevision/结算与清房标记）——只存本次运行态，不写持久档。
- **新增 `DungeonSequenceParser.h/.cpp`**：严格 JSON 解析（schema_version=1、重复 dungeon_id/
  单房序列/非正 XP/序列内重复房 id/错版本全部具名拒绝）。
- **新增 `DungeonCoordinatorSubsystem.h/.cpp`**：GameInstance 生命周期运行态所有者——StartDungeonRun
  （同时只允许一个 run、代数/settlement token 铸造）；逐世界 BindSession（URoomSessionSubsystem 是
  WorldSubsystem，每个新房间的 pawn BeginPlay 重绑）；OnRunEnded 消费（标记清房；末房一次性结算：
  合成 FRoomResult 携带地城身份与 xp_reward、经注入 RewardProvider 创建一次 PendingReward、
  Profile::RecordDungeonCleared + RecordRoomCleared，重复清房不二次结算）；OnExitAccepted 消费
  （仅当前房：门口快照 HP/MP/冷却剩余 → 房序推进 → 注入 TravelProvider 过图；失败回安全菜单；
  末门结束 run 回菜单）；ConsumePendingRoomSnapshot（下一房一次性消费快照）。
- **`RoomSessionSubsystem`**：新增 OnExitAccepted 委托（BeginExit 成功时广播当前房 id + run id）。
- **`HealthComponent`**：新增 SetHealth（钳制 0..Max，不触发死亡委托）。
- **`SkillLoadoutComponent`**：RestoreCooldownRemainders（剩余秒数在新世界时钟上重排，绝不跨世界
  比较旧绝对时间戳）。
- **`PrototypeCharacter`**：BeginPlay 重绑协调器；HandleRoomRunStarted 消费快照（HP 钳制恢复、
  MP、冷却剩余重排）——过图 MP/冷却携带；普通自由选关（无 run）语义逐字节不变。
- **`PrototypeHUD`**：run 中的清房不再走逐房间结算 UI——内部房直接抑制，末房绑定协调器合成的
  地城结算（"完整地城结算"语义）。
- **敌人**：Data/enemies.json 新增 dungeon_goblin_proto（HP 80、攻击力 8、预警 0.45s、纵深容差
  40cm；melee_grunt 参数不动）+ DA 资产生成 + MeleeEnemy 的 SetEnemyDefinition 哥布林视觉换装
  （引用 M6-008 ArtValidation 哥布林网格与待机动画，缺资产时回落 Quinn）。
- **数据**：Data/dungeon_sequences.json（dungeon_lorien_double = room_combat_01→02，xp 120）。
- **测试**：新增 `Tests/DungeonRunTests.cpp` 2 条——序列解析（实表 + 五类具名拒绝）；协调器全
  生命周期（双 run 拒绝/未知地城拒绝/内部房无结算/门口快照与房序推进/一次性消费/末房恰好一次

## 限制与注意

- **两房 waves 未重定向到 dungeon_goblin_proto**（已回退）：ARoomTrigger 的敌人解析是 M2-016
  的单敌路径（EnemyDefinitionPath 固定加载一个 DA 供所有 wave 使用），重定向需要按房敌人解析
  重构；首跑实证会破坏共享房的出生链（M5_054/M5_073 出生数为 0）。02 文档 §7 的执行默认
  （"首期敌人行为可基于当前 melee_grunt 通过现有敌人表配置调整"）认可本切片：哥布林的配置行、
  DA 资产与视觉换装已交付，wave 重定向与按房敌人解析属后续小卡。
- 菜单的"连续模式"入口按钮未接（启动 API 已就绪：StartDungeonRun + EnterRoom(room 1)）；M6-002
  选关 UI 的入口行属表现层后续。
- 过图旅行生产绑定（TravelProvider → GameFlow::EnterRoom）需在 GameFlow 侧接一行；当前生产
  路径的菜单→房间进房与自由选关一致，地城第二房的自动过图走该 seam。
