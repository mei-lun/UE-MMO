## 已知限制

- **C++ 单条校验只查 MeleeAttackId 非空**；"ID 在 M1 目录中存在"的跨条目校验按卡面留 M2 后续目录/房间任务（本卡在 JSON 数据层以测试强制）。
- 本卡只做定义+JSON+校验：`UEnemyDefinition` 未接到 TrainingEnemy（禁改）或任何角色/AI 上，追击、纵深对齐、攻击执行归 M2-002 等后续任务。
- MoveSpeed/AttackRangeX 按有限且 >0 校验（零速/零接近距离视为非法）是本卡设计选择；未来若引入静止型近战需放宽该规则。
- `SpawnedAtGameSeconds` 是定义实例上的运行时状态（非 UPROPERTY 数据），默认 0 等价"0 时刻出生"；真正的出生接线（谁调 MarkSpawned）归 M2 房间/生成任务。
- JSON 读取沿用 M1-008 教训的手写解析器（Json 模块不在 UEMMO 链接线），解析器为 M2_001 命名空间内的独立副本；后续若多文件复用可再抽取（不在本卡文件范围）。
