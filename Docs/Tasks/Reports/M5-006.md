### 接口（实际签名）

```cpp
// 六表门禁：weapons/projectiles 的全部引用 + 旧四招完整集合 + 表内重复 ID 纵深防御
TArray<FString> ValidateAllReferences(const FParsedCombatConfig& Config);

// 完整门禁：以上 + presentations 表（FParsedCombatConfig 由 M5-007 冻结为六表，
// presentations 在其外，故用两参入口携带）
TArray<FString> ValidateAllReferences(const FParsedCombatConfig& Config, const TArray<FCombatPresentation>& Presentations);
```

检查清单（每条错误命名 表名+行 ID+字段名+缺失 ID，格式与 M5-005 `ValidateCombatDataReferences` 一致）：

- weapons：非空 `damage_profile_id`/`ammo_id`/`projectile_id` 逐一解析到 damage_profiles/ammo_types/projectiles。
- weapons（melee）：`melee_attack_ids` 必须是完整旧四招集合 light_01/light_02/launcher/aerial_01（未知 ID、缺成员、重复 ID 分别报错，接口约定 §7"未知/不完整 AttackSet 校验阶段拒绝"）；每个 attack id 必须同时存在同名 attack_reactions 行（reaction_id 引用）与 damage_profiles 行（攻击数值）。
- projectiles：`damage_profile_id` 与 `explosion_damage_profile_id` 解析到 damage_profiles。
- presentations（两参入口）：每行 `reaction_id` 解析到 attack_reactions；每个 attack reaction 恰好一张 presentation（缺映射、重复映射都拒绝）；presentation_id 表内唯一。
- 重复行 ID：六表 + presentations 在结构级纵深防御（文件级已由 M5-005 解析器拒绝，候选结构可由其他代码路径组装）。
- 正例通过不按 weapon_id 写特殊分支：合法多弹丸（pellet_count=5）与 heavy/boss 目标策略直接通过。

## 已知限制

1. **样例表 damage_profiles 对齐缺口未修（需协调者决策）**：shipped `weapons.json`/`projectiles.json` 引用 `physical_10`/`explosive_40`，而 003 样例 `damage_profiles.json` 只有旧四招（M5-005 报告已记录该缺口）。本卡 Data/** 冻结，未改数据：原始 shipped 表过门禁时如实报告且仅报告这 10 条 damage_profile_id 悬空（4 武器 + 5 弹丸 + 1 爆炸，测试 `ShippedTablesIntegration` 逐条钉死）；测试侧补齐两行后全绿。**在样表修复前，不得把本门禁硬接到 `LoadCombatDataDirectory`**，否则会拒绝现有 A 段源表。
2. **target_reactions→presentations 引用不可表达**：冻结的 `FTargetReaction`（M5-003）没有任何引用字段，presentations 只映射 attack reactions，该边在值类型中不存在，无从校验（头部注释如实记录，未虚构检查）。
3. **单参入口不含 presentations**：`FParsedCombatConfig`（M5-007 冻结）只有六表；presentations 由两参入口携带。调用方持有一份完整目录数据时应使用两参入口。
4. **资源路径存在性不做**：可选表现资源缺失按接口约定 §6/M5-017 回退文本日志，必需资源门禁归 cook/catalog 启动侧；本卡只校验业务 ID 引用。
5. **tags/target_filters/item 映射/存档别名环**：无冻结值类型承载（target_filters 尚无解析类型、items.json 规范化属 007、别名 manifest 属 047），均未实现；任务卡第 3 步中"循环"在当前值类型下无任何可成环的引用边（所有边都指向纯 ID 表）。
6. 自动化均为纯逻辑测试，无键鼠试玩项；本卡不涉及人工关卡。
