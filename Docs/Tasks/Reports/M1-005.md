## 目的

按接口约定第 2 节实现 `FCombatWindow{StartFrame,EndFrame}`：窗口为半开区间 `[start,end)`；`Contains(Frame)` 判定 `StartFrame <= Frame < EndFrame`；`Crosses(PreviousFrame,CurrentFrame)` 判定推进经过的整数帧 `(Previous,Current]` 是否与窗口相交（初始 `Previous=-1`，重复同帧不再次经过，非正向推进返回 false）；`IsValid(Duration)` 判定 `StartFrame >= 0 && EndFrame > StartFrame && EndFrame <= Duration`。只依赖 Core，仅头文件（inline），不改成闭区间。

## 实际修改

- `Source/UEMMO/Combat/CombatWindow.h`（新建，仅头文件）：`FCombatWindow` 三个方法 inline 实现。`Crosses` 先拒绝非正向推进（`CurrentFrame <= PreviousFrame` 返回 false），再用 O(1) 判定 `max(StartFrame, PreviousFrame+1) <= min(CurrentFrame, EndFrame-1)`（`FMath::Max/Min`，经 `CoreMinimal.h` 可用）。
- `Source/UEMMO/Tests/CombatWindowTests.cpp`（新建）：4 个测试（`UEMMO.Tasks.M1_005.ContainsBoundaries / CrossesBoundaries / CrossesInitialFrame / IsValidDuration`），无 Actor/World 依赖，纯数据结构断言。
