## 验收对照

- **同seed方向一致，不同pellet不共用ID；散布0为直线**：`SameSeedReproducibleDirections`——同 seed 背靠背两次规划方向逐分量相等（共享流会泄漏状态使第二次发散，此即"不扰共享随机数"证明）；另一固定 seed 方向集发散；`FPelletIndex` 恰 0..N-1 各一次（`Seen` 数组逐位钉住无重复/无遗漏）。`ZeroSpreadIsStraightLine`——8 弹丸 × ±Facing 全部 `Direction.Equals((±1,0,0))` 精确。
- **±Facing与Y纵深/玩家高度起点正确，缺必需socket可定位**：`FacingMirrorsXOnlyNotY`——32 弹丸 ±Facing 同 seed：Y/Z 分量逐 pellet 相等、X 逐 pellet 反号、全部单位长度且偏离角 ≤ 12°；起点 `(20,30,80)` 偏移在 +1 → Feet+(20,30,80)、-1 → Feet+(-20,30,80)（X 镜像、Y 纵深/ Z 高度直通）。`SocketOptionalMissingIsLocatable`——解析 socket 生效（`bUsedSocket`、位置=socket）；可选 socket 缺失回退偏移（`bSocketFellBack` + `FallbackSocketName` 可定位）；必需 socket 缺失整体拒绝 `RequiredSocketMissing`、detail 含 socket 名、零弹丸零扣弹；无 socket 名纯偏移无回退标记。
- **pellet_count越界拒绝；全体容量不足无半串/半扣弹**：`PelletCountAndCapacityAtomic`——0/-1/33 全部 `InvalidPelletCount` 拒绝、`RoundsConsumed=0`、零弹丸；容量 4 < 8 → `CapacityInsufficient` 整体拒绝零输出；恰 8 容量全串规划。`FullVolleyConsumesOneRound`——8 弹丸全串 `RoundsConsumed=1`、索引唯一、单位长度、锥内；单弹丸恒 index 0。
- **每步走契约**：纯值规划器不触碰 Actor/伤害服务（卡面"不改Actor/伤害服务，产出ShotPattern纯值"）；`FPelletIndex` 复用 CombatEventTypes.h 既有类型（§0.1），拒绝枚举独立命名不吞原因（§2）。

## 集成决策（卡面授权范围内）

1. **调用方注入 socket 世界位置**：纯值类型不持 World（契约 §0.5），socket 解析归调用方（027/033 接线时传 `MuzzleSocketWorldLocation` 指针，nullptr 表示解析失败）；规划器只做选择与回退语义。
2. **容量探针由请求携带**：`AvailablePelletSlots` 是调用方（022 事务/027 `ReserveProjectiles`）预检的弹丸槽位余量；规划器在纯值层先做事务式校验，保证"无半串"在数学层成立，Actor 层预留仍是 027 职责。
3. **圆盘均匀采样（sqrt 半径）**：散布密度中心密边缘疏（真实霰弹枪语义）；`r = Spread·sqrt(u1)` 保证偏离角 ≤ SpreadDegrees，Y（纵深）/Z（高度）平面偏移 + X 基线合成——不需要欧拉角，Facing 镜像天然只影响 X。
4. **散布 0 不消耗随机流**：直线弹丸零采样，`Seed` 完全不参与输出——散布 0 与 seed 组合仍确定性。
5. **测试崩溃防线（红→绿流程改进）**：桩全拒绝时两个用例直接索引空 `Pellets` 数组把编辑器进程打死（exit 3、matched=0，17-38-07）；修正为前置 guard（`TestTrue` 失败 + `AddError` + return false），红阶段从此以命名断言失败录红。该模式沿用 022 rig.Build 先例，后续用例（026+）写桩期断言时先 guard 再索引。
6. **拒绝复用词表**：4 个 `EShotPatternReject` 值独立命名（非 `EFireReject` 映射）——本类型不是火路径策略而是规划纯值，与 022 门链枚举平级、不互相吞并；detail 一律点名违规字段/socket。

## 限制与移交

- 生产接线（谁调 `PlanShotPattern`、socket 如何解析、seed 从何而来——建议从 `ShotId`/`Epoch` 派生保证逐 Shot 专有）归 M5-027/028/033 谱系；本卡只冻结纯值语义。
- `Facing` 以 float ±1 传入（横版惯例）；非 ±1 值未校验（调用方契约），镜像语义只对 X 分量成立。
- 散布角语义为"对基线的球面偏离角"（Y/Z 平面均匀），非锥体立体角均匀；3D 横版俯仰散布可复核性优先于立体角统计保真。
- 自动化不等同真实键鼠试玩；本卡为纯值规划器，无人工关卡项。
