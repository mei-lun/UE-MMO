## 实现决策（卡面授权范围内）

1. **爆心 = 首个 blocking 碰撞点（Hit.ImpactPoint）**，`bDetonated` 标志先于一切查询/回调写入——重入、多 Collider、同帧多段全部天然一次。
2. **半径查询重过滤而非信任 sweep**：`OverlapMultiByObjectType`(ECC_Pawn) 只作候选收集，逐 actor 过 028 共享 `ClassifyProjectileHitActor` 只提交 Hostile，TSet 按 actor 去重（多体靶一个实体一次伤害）；距离与遮挡以 `GetComponentsBoundingBox().GetCenter()` 为目标点。
3. **遮挡线不含 Pawn**（WorldStatic+WorldDynamic）：Pawn 之间不互相挡爆炸；起点沿爆心→目标方向偏移 1cm，防爆心贴墙时 trace 自命中遮挡体。
4. **衰减应用点 = `FDamageProfile::BaseDamage` 逐目标副本缩放**（011 公式缩放语义在 DamageProfile 层）：`Scale = Lerp(1, EdgeScale, clamp(Dist/Radius,0,1))`，AttackPower=0、Defense=0 时 FinalDamage = round(BaseDamage × Scale)，血量断言反推逐一验证。
5. **爆炸与穿透互斥在 Begin 拒绝面再钉**：PierceCount > 0 拒绝（爆炸策略无穿透语义）；`Configure` 允许 radius 0（接线复用合法值），`Begin` 拒绝 radius ≤ 0（爆炸策略存在前提）。
6. **零残留**：终结后 `IsFinished()==true`，无委托无定时器无组件激活，寿命归 027 引擎 LifeSpan。
