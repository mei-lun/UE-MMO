## M1-H01 试玩步骤（用户执行，AI 不代签）

准备：编辑器 `Scripts/Run.ps1`（或双击 `UEMMO.uproject`），或独立包 `Artifacts/Package/Windows/UEMMO/Binaries/Win64/UEMMO.exe`。训练房在 `/Game/UEMMO/Maps/L_TrainingArena`（独立包可在快捷方式后加参数 `/Game/UEMMO/Maps/L_TrainingArena`；编辑器在 Content Browser 双击该地图后运行）。

1. **开调试面板**：按 `F1`，出现 "DEBUG OVERLAY (M1)" 面板、右上敌方血条、左下连击位。
2. **走位**：`A/D` 左右、`W/S` 纵深；走到训练假人正面约一个身位（面板 HitBox 出现且套住假人时距离合适）。
3. **完整连招**（四段，节奏是"按一下、看起手、再接下一段"）：
   - `J`：light_01 起手；
   - 约 0.2–0.4 秒内（light_01 取消窗）再按 `J`：链 light_02；
   - 约 0.3–0.5 秒内（light_02 取消窗）按 `K`：上挑 launcher，假人被打浮空；
   - 上挑命中后立即按 `Space` 跳取消，人在空中；
   - 空中按 `J`：aerial_01 追击浮空中的假人。
4. **预期现象**：四段伤害 10/14/18/12（血条 100→90→76→58→46）；假人浮空约 1.4 秒、峰值约 2.5 米；落地倒地→翻身→恢复站立；伤害数字飘出、连击计数累加；连不上招时看面板 Buffer/State 行（按键过早/过晚会被窗口拒绝，这是设计语义）。
5. **复位**：`R` 一键会话复位（假人满血、双方回 Free），可反复试连招。
6. **验收反馈**：确认手感（打击节奏、浮空高度、连招窗口宽严）后在 TASKS.md 的 M1-H01 上给出结论；技术侧已无待办。
