## 验收对照

- **三发各一Shot，重复press或长按不叠加两串**：`PressFiresOneBurstOfThree`——无 press 轮询零发零扣；press 后按 1/8+2/8+2 帧节奏恰 3 发（每发独立 ShotId、弹匣 30→27）、长按 20 帧零发（无新边沿即拒绝 "no burst is armed"）；新 press 再开新串共 6 发书 24。`RepeatPressAndHoldDoNotStack`——双 press 边沿仍一串 3 发、串中 press 忽略、长按 20 帧 0 发不叠加。
- **已开始点射松键可继续**：`ReleaseBeforeStartCancelsAfterStartContinues`——press+release 后 10 帧 0 发零扣（解除武装）；开始后 release 剩余子发照常打满 3 发书 27。
- **只剩2弹发2次后拒绝第三；中断不补发**：`InsufficientRoundsFireLegalSubShotsOnly`——火书钉 2 发 → 前 2 子发合法打出书归零 → 干发探针（推时钟过冷却窗）显式 `MagazineEmpty` 零副作用、无负弹药 → `CancelPendingBurst` + 换弹两相事务书回满 30 → 旧串 10 帧不复发 → 新 press 开新串。`DeathAndSwitchCancelPendingSubShots`——串深 2 后 `NotifyOwnerDied` → OwnerDead 明确拒绝 → 取消 → 复活后 10 帧 0 发 → 新 press 新串；拆绑 `ApplyEquippedWeapon(nullptr)` → 取消 → 重绑后 10 帧 0 发 → 新 press 新串（拆绑/重绑均走 020 装载事务）。
- **暂停/卡顿边界一致，所有发射通过022事务**：`PauseAndStallBoundaries`——暂停冻结时钟 10 询 0 发零扣（锚不因暂停错动）、解冻后 8+2 边界续发至 3 发书 27 不补射；0.5s 单帧长卡顿恰准入 1 发、同帧第二询 false 零副作用、后续 8+2 补完、burst 完成后 0.5s 帧 0 发（无边沿不再开火）；全程 `ShotTimes.Num() == GetCommittedShotCount()`（每发都走 022 原子事务：一准入一扣弹一序列一冷却）。

## 集成决策（卡面授权范围内）

1. **press 边沿 API 放在具体类而非 IFirePolicy**：策略无法从 `ReserveShotCapacity` 调用区分「新按下的首发」与「串中续询」，故 `NotifyTriggerPressed/NotifyTriggerReleased` 是 `FBurstFirePolicy` 具体类成员；输入层 M5-033 持有实例并转发边沿，无需组件改动。
2. **取消是调用方义务**：组件死亡/拆绑仅在 `bShotInFlight` 时调 `AbortReservation`（每帧 release 模式下死亡不触达策略），换弹完全不触达策略——「死亡/切换/换弹取消剩余」由调用方（M5-033）显式调 `CancelPendingBurst`；测试钉住取消后不复发、新 press 新串，不依赖超期自取消（会误杀卡顿场景）。
3. **首发预留是事务性的**：press 边沿在 `ReserveShotCapacity` 消费、在 `AbortReservation` 回滚——被后续门（冷却/在飞/扣弹失败）拒绝的首发不消耗边沿；`CommitShot` 才把边沿落成 `BurstCount - 1` 个待发子发，锚按实际提交时刻铺设。
4. **锚不清松键**：子发锚保留至该串完成或取消——「已开始点射松键可继续」就是锚 + pending 的自然结果；`NotifyShotReleased` 无策略状态可清。
5. **拒绝复用 022 词汇**：策略拒绝统一映射 `EFireReject::ReservationFailed` + 明细（hitscan-only / 子发未到点 / 无武装边沿），不新增平行枚举。

## 限制与移交

- `BurstCount` 默认 3、`SubShotIntervalSeconds` 默认 0（完全让位组件冷却）：生产取值（按武器定义 burst_count/interval 换算）由集成者在注册策略时设置，配置来源接线归 M5-033。
- 死亡/切换/换弹时调用 `CancelPendingBurst` 是 M5-033 的接线义务；当前组件死亡门已阻断子发发射（OwnerDead），故漏调不会发射错误子发，但会残留 `HasPendingBurst()==true` 使输入循环空轮询。
- 仅授权 hitscan；投射物交付归 026..032 Projectiles/*，散射/多弹丸归 M5-025——均经 `SetFirePolicy` 注册各自策略文件。
- 自动化不等同真实键鼠试玩；本卡为纯逻辑策略，无人工关卡项。
