## 输入、输出与约定（用户 2026-09-30 指定）

记录四类内容到专用日志文件：①角色所有操作（攻击起止/上挑/跳取消/穿脱/领奖/进出房/复位）②所有功能状态（战斗 ActionState/房间状态/等级 XP/装备槽/存档结果）③键盘输入（按下/抬起，含方向键与全部绑定键）④程序响应（伤害/升级/掉落/保存结果/失败原因）。**跨日清空**：日期变化时清空日志文件重开。

## 实现要求

- `Source/UEMMO/Logging/OperationLogSubsystem.h/.cpp`（新建）：`UOperationLogSubsystem : UGameInstanceSubsystem`（GameInstance 级跨地图）：
  - 文件：`FPaths::ProjectSavedDir()/OperationLogs/OperationLog.log`；每条格式 `[HH:MM:SS.mmm][分类] 内容`；逐条追加落盘（崩溃安全）
  - **跨日清空**：每次写入比对记录日期与 `FDateTime::Now()`（经可注入时钟函数 `SetNowProvider` 供测试），日期变化 → 清空文件重写当日头部（日期+构建标识）
  - 统一 API：`Log(FName Category, const FString& Message)` + 便捷 `LogInput/LogState/LogResponse`
  - 自动订阅（RegisterPlayer(APrototypeCharacter*) 后绑定）：CombatComponent Started/Finished/HitConfirmed、RoomSession OnRunStarted/OnRunEnded（会话由 World GetSubsystem 获取）
- 接线（最小增量）：PrototypeCharacter 输入处理处记录离散键盘事件（按下/抬起：方向键/X/Z/C/F1/F2/QWERASDF——移动轴连续值不逐帧记录，只在方向变化时记一条）；RoomSessionSubsystem 状态转移处、ProfileSubsystem AddXP/NewProfile/ResetNewGame 处、RewardService BeginReward/ClaimPendingAtomic 处、SaveService 保存/加载结果处各加一行 Log 调用（经 GetSubsystem 获取，无实例安全跳过）
- 性能：每次写入量小、频率低（离散事件），逐条开关文件可接受；不记连续移动轴数值

## 独立验收

- 驱动一次"输入→攻击→命中"序列后，日志文件按时间序包含：按键输入行、攻击 Started/Finished 行、命中行（含伤害数值）
- 跨日清空：注入两次不同日期的写入 → 文件只含第二次日期头部与内容（首次内容被清空）
- 未注册玩家/无 World 时调用各 Log 不崩溃；日志写入不影响既有测试全绿
