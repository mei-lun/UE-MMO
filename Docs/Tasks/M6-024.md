# M6-024 完整状态与技能补齐（P4）

方案来源：接入方案 §4.1/§6.3/§8（P4）。依赖 [M6-023](M6-023.md)。

## 目标与边界

- 为普通受击、倒地、起身、死亡、复活接入 DNFM 画面（有各自画面，不得用待机或单张图代替，方案 §6.3）；复活血清理旧显示实例回待机。
- launcher（上挑，40 帧 [12,17)，jump 取消）与五技能（singlekick/damagelowkick/throwsand/earthbreak/stomp）逐招接入统一时钟：姿势、位移显示、命中时刻对齐现有窗口。
- 音效仍由现有统一调度播，不双播（方案 §6.2）；原版技能若有缩放/旋转/特效帧，走 M6-020 拦截路径显式处理。
- 不新增伤害通道，不改 Combat 配置。

## 验收条件

- 逐状态、逐技能可辨识且正确结束；无隐含待机替代、无无限等待帧。
- 自动化测试覆盖受击打断、倒地→起身、死亡保持末帧、复活复位、每技能命中窗同步；`Test.ps1` 通过。
- `Test.ps1 -Render` 截图逐技能姿势核对并人工查看。
