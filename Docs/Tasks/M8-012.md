# M8-012 P02-C 竹林碰撞与摄像边界

对应 07 计划 P02 拆卡 3。依赖：M8-010、M8-011。

范围：

- 通行网格实机裁决：按 M8-010 两假设（0/2 语义）构建可走带碰撞（地面 physical + Y 纵深带边界），实机走位验证哪套成立；未解释字段保持显式记录，不猜第三套。
- 玩家在竹林段：X 走位至边界被挡、Y 纵深带内自由走位、跳跃三阶段落地正确、脚底不穿地面/不漂移。
- 摄像边界：镜头跟随地面锚点不穿帮（近景遮挡人物时排序正确）；前后（近/中/远 Y）遮挡测试。
- 自动化：按 Test 口径新增竹林段专项（移动/碰撞/跳跃断言），纳入 TestAutomation 可筛选。

验收：自动化专项全绿且本次生成 JSON success=true；`-Render` 实机截图（走位/跳跃/纵深/遮挡）经协调者实看；M8-010 假设裁决结论记录（哪套语义成立、未解字段清单）。P02 总验收达成：一段原色竹林可走、能跳、前后遮挡正确。
