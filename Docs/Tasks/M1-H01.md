# M1-H01 · 用户连招手感验收

- 前置：M1-039、M0-H01均DONE。
- 负责人：用户；AI负责准备试玩包与记录。
- 报告：Docs/Tasks/Reports/M1-H01.md，从模板创建。

## 试玩项

1. 运行M1-039实际交付的新包，确认显示版本、构建时间和操作说明。
2. 用J衔接两段普攻，分别试提前按、正常按、明显太晚按，确认不会自动无条件接招。
3. 用K上挑、Space追击、空中J，完整连招重复至少3次；落地后双方状态恢复。
4. 把双方纵深拉开，攻击能明确打空；靠近后恢复命中。
5. R在攻击、浮空、死亡等状态下能复位；镜头不剧烈上下晃动。
6. 确认音效、伤害数字和命中停顿可辨认；逐项查看上挑/空中动作占位列表。
7. 用户明确决定：当前占位质量可接受进入刷怪阶段，或指定必须先改的问题。

## 状态规则

技术包备好后设REVIEW。只有用户明确认可才能写Human-Approved:yes、Verification:PASS并设DONE。若不通过，记录问题并添加独立修复任务，M2保持不可领取。AI不能以“自动测试通过”代替此项。
