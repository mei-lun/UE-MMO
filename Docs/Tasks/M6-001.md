## 输入、输出与约定

- `Data/rooms.json` 是关卡目录唯一源（M5-069 唯一源数据原则）：行序即菜单展示序；每行生成同名数据资产 `DA_<room_id>` 到 `/Game/UEMMO/Rooms`（该目录已 always-cook，M5-074 先例）。
- 生成脚本从"只写死 combat 一行"扩展为逐行生成；行内可选新字段 `display_name`（ASCII 英文，本地化后续任务）复制进 `URoomDefinition::DisplayName`。
- 运行时目录：`UGameFlowSubsystem` 新增关卡目录查询——按 rooms.json 行序返回 `URoomDefinition*` 列表（每行解析 `DA_<room_id>` 软路径；行缺资产时记错误行并跳过，不让整目录失败）。`Data/rooms.json` 缺失/结构非法时目录为空并给出可读错误。
- 兼容面：`GetSelectableRoomDefinition` / `GetCombatRoomDefinition` / `GetSystemTestRoomDefinition` 三个既有入口保留且行为不变（M3-030 boot 链、M5-018A 契约不动）；SystemTestRoom 不进目录（它来自 test_room.json 驱动链，保持菜单附加项）。
- `SelectableRoomCount = 1` 契约退役：由目录行数取代；`GameFlowTests` 的钉子改为"目录行数 == Data/rooms.json 行数且顺序一致"。
