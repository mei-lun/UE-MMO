# M5-062 · 实体子弹飞行轨迹可见性

前置M5-061，状态唯一来源TASKS.md。用户反馈："子弹有效果但是看不见弹道"。

## 范围

- 为现有实体子弹增加细亮、渐隐的短拖尾，保留弹头与实际速度/轨迹/碰撞；只记录已经走过的位置，不预测枪口到目标的整条柱体。
- 拖尾沿实际弯曲轨迹，限定长度、存活时间与段数；碰撞终点不得越墙，命中后短暂淡出；复位/离场清理，纯表现无伤害或碰撞。
- 复用引擎网格/UE原生材质，不引入外部素材。
- 验证实际路径几何、长度/段数上限、命中/超时淡出、复位清理和原实体伤害逻辑；完整Build、全量回归、资源保存后新进程重载、实际飞行/命中/消退截图及新独立包。

人工M5-H02继续由用户签收，不把静态截图与自动输入等同于真实可读性确认。
