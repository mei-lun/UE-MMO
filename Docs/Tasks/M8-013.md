# M8-013 P03-A 竹林动态对象与雾动画

对应 07 计划 P03 拆卡 1。依赖：M8-011、M8-012。对象：4 个 L2 层雾对象（46-49，键 `5b7b43a536fab1c1`，BossMap_fog，50.1s 循环，各 2 含图帧，f1 带 flip_y=true 染色 [255,255,100,255]）。

范围：

- 离线：f1 帧 flip_y 预烘焙为独立 PNG（确定性脚本，不依赖 UE 材质翻转语义）；从 placement/manifest 提取逐帧 delay_ms 时序。
- UE（协调者串行）：导入 f0/f1（f1 用烘焙版）纹理与材质；为 4 个雾对象各建双四边形（f0/f1 互斥显隐）；新增轻量 C++ 循环器（按 delay_ms 交替显隐，随地图保存）；重建地图并二进程 verify。
- 验收：-game 实机两时刻截图显示雾帧交替（协调者实看）；雾在远景层正确绘制（L2 深度）；不遮挡可走带语义；回归无新增失败。

验收补充：循环器参数（帧对、时序）由导入脚本按 manifest 数据化写入，不手调；两进程重载后循环器与引用完好。
