## 实现要求

1. **玩家 presenter**（`UCombatPresentationComponent`）：`SetSources` 订阅源组件状态机
   `OnPhaseChanged`（解绑对称）；受击相位（HitStun/Knockdown/GetUp）打断攻击表现与 Idle 拆除
   **当 tick 即时重同步**（闭合预留的"future interrupt-to-free path"一轮延迟盲区）；攻击内帧
   采样保持（**事件定动作族，采样定族内位置**）。
2. **敌人显示**（`AGoblinThrowerEnemy`）：BeginPlay 订阅；相位→动作决策事件化
   （Dead→down+末帧保持/Knockdown,GetUp→down/HitStun→damage_0/1）+ 每 tick 幂等重应用
   （首挂失败自动重试）；`ResolveDisplayAction` 收缩为保持门+死亡钉+Idle 速度切换。
3. 验收自动化：`UEMMO.Acceptance.M8_038.PhaseDrivenDisplay`——受击相位事件同 tick 翻转哥布林
   damage 姿态；ResetCombat 后 Idle 事件同步拆除攻击表现（`GetPresentedInstanceId` 只读缝）。
4. 回归：M8_031（状态机+技能）与 M1_009（M8-035 音频+M8-036 特效资产）不退化；全量冒烟绿；重打包。
