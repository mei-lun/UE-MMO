# M7-004 连续双房间地城

## 背景

Docs/DNF-Research/02-多职业功能实施方案.md §7 与 §9 第 5 步。前置：M7-003。

## 边界与内容

Data/dungeon_sequences.json 新增连续模式 ID，按顺序引用 room_combat_01/02（原自由选关不动）。
GameInstance 生命周期 FDungeonRunState：DungeonId、CharacterId、当前房索引、RunGeneration/
SettlementToken、带状态 HP/MP、按 SkillId 冷却剩余值、源配置 revision。ARoomExit BeginExit 发布
OnExitAccepted；协调器只接受当前序列刚清空的房间与当前代数。第 1 房清空只开门不结算；第 2 房
成功经现有 RewardService 一次结算，新增 DungeonClears 计数并纳入 A/B 完整性摘要。HUD 结果页
区分"房间结算"/"完整地城结算"。敌人新配置 dungeon_goblin_proto（正攻击力/预警/纵深容差，引用
哥布林模型），旧 melee_grunt 不动。

## 验收条件（02 文档 §9 第 5 步）

第一房失败、第二房失败、切图失败、重复领奖、过图 MP/冷却、旧世界弹体/委托清理；旧自由选关
逐房间结算回归通过。
