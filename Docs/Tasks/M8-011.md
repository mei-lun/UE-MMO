# M8-011 P02-B 竹林地面与分层材质 UE 构建

对应 07 计划 P02 拆卡 2。依赖：M8-005、M8-010。

范围：

- 离线（可并行）：按 atlas.sqlite 裁切 2 个唯一地砖定义图（84368d…/8460768a…，224×600）与 L1/L2/L5/L6/L7 层对象首帧（必要时全帧）PNG；产出 UE 放置中间数据（沿用 M6-011 `build_dnfm_layout_intermediate.py` 确定性管线模式），坐标经 M8-010 换算。
- UE（协调者串行执行）：编辑器 API 导入纹理/材质——Nearest/Clamp/无 mip、Unlit+TwoSided+Masked、Plane UV 1−v 翻转规则（M6-022/015 既定口径）；在竹林测试图按标定布置"入口段"：地面砖带 + 全部 50 对象分层放置（远景→前景）。
- 二进程重载验证（瞬态播放不等于落盘正确）。

验收：`-Render` 实机截图——人物站在原色竹林地面上（脚底与地面带对齐）、远中近层遮挡正确、无白板/黑块/描边错误；新进程重载 actor 数与关键位置一致；报告记录截图与重载证据。产出落地为可复现脚本+中间数据。
