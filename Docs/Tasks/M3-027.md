# M3-027 · 房间战斗视觉诊断与呈现修复

> 任务卡；进度以根目录 TASKS.md 对应行扇。

## 背景（用户第四轮反馈）

用户实测：X/空中攻击、C 跳可用，但 **Z 上挑"没有用"、攻击怪物无反馈、怪物不动、怪物无血条**。包内日志证实机制层全部正常（RunStarted/两波生成/18 次命中/3 击杀/波次推进）——缺口在呈现层或真实游戏循环与测试环境的差异。本卡：离屏复现用户会话 → 逐帧截图诊断 → 修复呈现缺口 → 截图复验。

## 实现要求

1. **复现**：打包 exe（或编辑器 -game）L_CombatRoom01 + RenderOffscreen，走真实生产链（走进激活区→波次→用 SubmitCombatInput/合法入口攻击）——每 0.3-0.5s 截图，覆盖：敌人出生、敌人接近、玩家攻击、命中反馈、上挑浮空。
2. **诊断**（对照用户四条反馈逐一取证）：
   - 敌人是否移动（两帧对比位置）
   - 玩家攻击 Montage 是否可见（出拳姿态 vs 站桩）
   - 命中时伤害数字/血条是否出现
   - Z 上挑命中后敌人是否浮空（两帧高度对比）
3. **修复呈现缺口**（按诊断结果，呈现层优先）：敌人受击反馈（最小：受击时材质闪红/击退位移——无受击动画资产）、伤害数字可见性（字号/位置）、敌人血条可见性（M3-026 已建，检查投影/遮挡）、上挑浮空可见性（确认冲量应用与 MovementMode）。
4. **复验**：修复后同流程截图对比。
