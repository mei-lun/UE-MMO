- **只做资源验收**：不接入战斗代码、菜单、房间流程，不改 PrototypeCharacter/Profile/GameFlow。

- 私有 DNF 参考图像不进入 UE Content，也不进入 Git；本卡产物只有 UE 内 uasset 与验收报告/截图。
- 多职业功能代码仍按 02-多职业功能实施方案.md 门禁：**资源 A/B 验收通过（用户签收）后才启动**。

## 实现步骤

1. `Scripts/Editor/import_dnf_art.py`（mode=create）：
   - 以 AssetImportTask 将两个绑定姿势 FBX 导入为 SkeletalMesh + Skeleton + 材质贴图；
   - 代表性动作（hero：idle/launcher/run_x；goblin：idle/telegraph/attack）随骨架导入为 AnimSequence；
   - 校验骨骼数、包围盒高度、材质与贴图引用；写 `Artifacts/Logs/dnf-art-import-report.json`。
2. 冻结帧截图（M1-036/M3-032 的 SceneCapture2D 方法）：侧视、斜前、斜后各一张 × 两角色，
   动作在显式时刻驱动；PNG 存 `Artifacts/Tasks/M7-001/`。
3. mode=verify：第二个独立编辑器进程重新枚举资产（二次进程重载核对），写 verify 报告。
4. 报告 `Docs/Tasks/Reports/M6-008.md` 记录命令、JSON、截图路径与限制；实现提交 SHA 回填总表。

## 验收条件

- create 与 verify 两个进程的 JSON 报告 success=true；骨骼数与 blender_validation.json 一致（23/22）。
- 高度核对：hero ≈ 183cm（±3cm）、goblin ≈ 125cm（±3cm）——与 Blender 1u=1m 约定一致。
- 三视角截图实际查看：站地、轴向（面朝方向）、材质贴图无丢失、动作帧可辨。
- CheckTaskBoard 通过；不签收任何人工 H 项。
