## 实现步骤

1. **排查两张"深色"材质渲染浅灰的根因**：打开 `M_VolcanoRockDark`、`M_VolcanoFloorBase` 材质图，逐项查 BaseColor 接线、线性/sRGB、自发光混入、Lit/Unlit 模型；修成深火山岩色（目标：地面明度显著低于岩浆带与岩壁高光）。fresh 进程重载验证，不把 Live Coding/瞬态当通过。
2. **岩浆带重做**（默认方案）：宽度 120→60cm、贴地 z=25→2、自发光改深橙红并加大对比、脉冲幅度收窄；两条光带两侧各加一圈暗色熔岩壳边条，消除"斑马线"读感。
3. **黑区填充**：BackWall 顶 1700→2200cm、宽度对齐镜头 FOV；44 块 OBJ 材质改双面且背面色为深岩色（消灭黑色矩形）；岩壁组间空隙补 1~2 条远景暗色山脊条。
4. **理顺 BackWall(y -780..-380) 与 FoundationBackdrop(y=-620) 的重叠**，避免互相穿插闪烁。
