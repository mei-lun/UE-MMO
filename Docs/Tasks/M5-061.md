# M5-061 · 普通枪械实体子弹与弹头表现

状态唯一来源为TASKS.md。前置M5-060。用户2026-10-17要求：“发射的是子弹，不是发射方块柱体，按照常规的来”“子弹是一个实体，有创建销毁，有规定的飞行弹道，和速度等参数”。

## 范围与设计

- 普通步枪、点射、散弹改为真实ACombatProjectile，每颗弹丸独立生成、按配置运动与碰撞命中、结束销毁；复用现有运动策略/统一伤害/生命周期，不新增平行战斗系统。
- 保留物品/武器稳定ID兼容背包，显示名称去掉误导的hitscan字样；历史射线后端可保留作独立类型，但玩家普通枪不使用拉伸方块梁。
- 弹头使用引擎网格构成细小圆润外观，沿实时飞行方向朝向；速度、弹道、寿命使用projectiles配置，直线有效距离由速度×寿命限定；不新造角色美术。
- 验收创建数、有限飞行时间、速度/位移、碰撞前不扣血、命中后销毁、超时清理、配置变化与重置/离场清理；Render观察弹头飞行而非整段光柱。
- 完整构建、全量自动化、资源生成后重载验证、独立新包及真实UI八武器复验；保留人工验收未签状态。

## 限制

供弹/持久化、载具、正式武器模型不在本卡范围。原MCP安装改动不得混入。测试代码需与实体弹模式一致，不沿用瞬时伤害断言。
