# M8-010 P02-A 竹林像素/世界标定

对应 07 计划 P02 拆卡 1。依赖：M8-005。输入：`Data/DNFMReplica/verify/map_bamboo.json` 的 calibration_inputs/ground。

范围（离线可完成，零 UE 写入）：

- 确定换算约定：px→UE cm 沿用格斗家已标定 s=1.7615cm/px（M6-022），保证人物与地图同尺度；场景 2D 像素坐标（x 右、y 下、z 为 y 修正）→ UE X 横向 / Y 纵深 / Z 高度，y-down 与 UE Y 轴符号关系给出显式假设与可检验预测。
- 地面高度：floor_height=120px、地砖 600px 高、y_top=40（y=floorHeight-80-originY 公式，origin 未恢复）→ 推导地面走带的世界 Z 与脚点落点；对 M8-005 的 object_foot_points 逐个换算出 UE 预期值。
- 通行网格：30×14、值 {0:280,2:140}（行0-9 全 2、行10-29 全 0）→ 给出"0=可走/2=可走"两假设各自的世界空间可走带预测（X/Y 范围），供 M8-012 实机裁决。
- 产出可执行 Python 转换函数（纯函数、确定性）+ calibration JSON（`Data/DNFMReplica/bamboo_calibration.json`）+ 断言清单（每条含数值预期，供实机核对）。

验收：转换函数对 ground 公式复现一致（自测断言全过）；两套可走带假设的数值预测完整；origin 未恢复等未知值显式记录处理方式；报告记录推导与证据。不改 UE 资产。
