## 实现要求

1. **提取**：`Scripts/DNFM/build_skill_fx.py` → `Data/DNFMReplica/characters/fighter/fx/`
   八张条带页 + manifest（源 .img 路径/帧数/canvas/frame_ms/sha256）；确定性双跑校验。
2. **导入**：`Scripts/Editor/import_skill_fx.py`：纹理入 `/Game/UEMMO/Combat/FX/T_FX_*`
   （nearest），每张 duplicate `M_ThrowStoneVisual` 换 PageTex → `M_FX_*`（UVRect 契约
   pageUV = UVRectMin + vec(u, 1-v)·UVRectSize 原样继承）；verify 模式核资产在盘。
3. **数据**：`combat-attacks.json` 四攻击行新增可选 `cast_fx_material_path/cast_fx_frames/
   cast_fx_frame_ms/cast_fx_scale_cm` + `hit_fx_*` 同构四字段；`UAttackDefinition` 对应八成员
   （软引用+帧数/帧时/厘米标高，0 帧数=无特效）。
4. **运行时**：新 `AFxFlipbookActor`（一次性播放 flipbook 面片：Plane+MID UVRect 推进、
   播完自毁、无碰撞无阴影；母材质读 PageTex 求纵横比）；presenter `HandleStarted`/
   `HandleHitConfirmed` 预解析 FX 材质非空才生成（cast 锚在施放者前上方向，hit 锚在
   `WorldHitLocation`；敌人攻击无特效字段属常态形态不生成）。
5. **生成管线**：`create_combat_assets.py` 校验（可选材质路径可加载）/应用/校对扩展八字段。
6. **验收自动化**：`AttackAssetTests` 四攻击行 FX 材质路径+可加载断言（特效半边，与 M8-035
   音频半边合成"特效/声音资产引用全部可加载"全句）。
