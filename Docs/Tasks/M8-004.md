# M8-004 P01-C 神枪手源依赖核实

对应 07 计划 §4 候选表"神枪手"行与 P01。目标：为第三职业（实际远程普攻）提供可解析的精确源键清单。

范围（全程只读源库）：

- `script/character/gunner/animation/` 全部 .ani 枚举，逐动作帧数/时长/变换；确认 rest/move/attack1/attack2/jump/jumpattackready/die 及受击/起身候选。
- 衣装与手持武器/枪械层：固定衣装组合定位与帧平行性验证；明确枪械层挂接（哪层、哪帧、偏移）。
- 左右射击：镜像处理证据（翻转帧标记）；普攻/技能枪口锚点逐帧像素坐标 + cm 换算建议。
- 六技能候选（膝撞/挑击、浮空射击、滑铲、回旋踢、投掷爆炸物、连续射击为意图）：按证据提名，区分"实际远程弹体技能"与"通用枪械占位效果"；每招给身体动作+弹体/特效+声音依赖；证据不足如实标注。

验收：`Data/DNFMReplica/verify/gunner.json` 记录衣装/武器层映射、基础动作、枪口锚点、六技能候选与弹体依赖；gaps 逐条列出；合成预览 PNG 交协调者实看。零写入 DNFM 目录。
