# M5-077 · 投射物命中账本清理接线

- 前置：M5-050；预计 30–60 分钟。M5-050 压测调查发现的生产缺口①：**投射物生产链从不调用 `FHitLedger::EndShot`/Reset**（`PrototypeCharacter.h:512` 的 `ShotHitLedger` 只 Bind 不清；近战已有先例 `CombatComponent.cpp:1577`）。
- 后果：持续投射物命中累计 ≥256 个不同 shot 后，新命中被 `EHitLedgerRejectReason::CapacityFull` **静默拒绝**（无表现、无日志告警）。M5-050 测试已在驱动侧验证"齐射退役时 EndShot"的清理形态可行（100 轮回基线）。
- 实现：投射物齐射/单发退役（寿命到期、离场、命中耗尽）路径由生产驱动调用 `EndShot` 释放事件/控制键（保留 tombstone 拒绝迟到重发的既有语义）；为 CapacityFull 拒绝补一条可定位日志。回归 M5-050 三用例 + 武器/命中相关旧套件。
- 验收：压测 200 并发长时间火力下 `ledger_events_held` 回落、无 CapacityFull 拒绝；近战 EndShot 既有用例不回归。
