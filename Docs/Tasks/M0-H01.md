# M0-H01 · 真实键盘与镜头验收

本项由用户试玩，AI只负责准备、记录和修复。状态与负责人见TASKS.md。

## 前置与范围

- 前置：M0-003、M0-004，均为历史完成基线。
- 当前无需等M1，使用现有基础包即可。
- 不要求验证当前不存在的伤害和连招。

## 操作与独立验收

1. 启动 `Artifacts/Package/Windows/UEMMO.exe` 或 `Scripts/Run.ps1`，点击游戏窗口取得焦点。
2. A/D分别移动屏幕左/右；同时按A+D应抵消，不改变镜头侧面方向。
3. W/S分别向场地远处/近处移动，不能被锁在单轴；单独W/S不让角色朝镜头转身。
4. Space可跳起并落回地面，R可回出生点且没有残留速度。
5. 左右转向时镜头不绕人物旋转；人物和HUD可见；边界不会无限掉出房间。
6. 用户明确反馈“通过”或指出哪项不符合预期。
