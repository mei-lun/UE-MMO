## 背景（用户试玩发现）

X/Z 在真实游戏中无反应：`APrototypeCharacter::Tick` 只调 `Combat->TickCombat(DeltaSeconds)`，从未调用 `SetInputClockSeconds`，`bInputClockInjected` 恒 false → Free 态起手/取消窗消费全部被门控关闭。朝向来源也未接线（组件存储值 0）。

## 实现要求

- 每帧 Tick 顺序：`SetInputClockSeconds(World->GetTimeSeconds())` → 注入 Facing → `TickCombat(DeltaSeconds)`。
- 朝向：`SetFacingProvider(TFunction<int32()>)`（与 AirStateProvider 同风格），PrototypeCharacter 返回当前朝向 ±1（由水平输入方向/yaw 推导，与 M1-029 Facing 逻辑一致）。
- **真实角色在环验证（核心）**：新增 game 模式自动化（复用冒烟/训练房模式）：真实 APrototypeCharacter + L_TrainingArena 敌人，不注入测试时钟（走角色自身 Tick 接线），以 SubmitCombatInput 模拟 X/X/Z 按键序列（按世界时钟排程），断言：敌人 HP 100→90→76→58、攻击 Started/Finished 事件、浮空发生。此测试锁死"游戏侧接线"不再回退。
- Package 冒烟可选追加（协调者负责重建包）。
