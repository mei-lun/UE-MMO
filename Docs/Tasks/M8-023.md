# M8-023 P06-D 侧视取景重对齐（DNF 构图标定）

对应 07 计划 P06 拆卡 4（用户首轮试玩反馈"贴图位置不对"的取景根因）。依赖：M8-022。

范围：

- 侧视相机臂长重标定：M0 的 1700 使 192cm 角色仅占屏高约 11%（世界被拉远 2.8 倍，构图整体失真）；重标至 660 使角色约 1/3 屏高、脚下留石板地面、竹丛近景层叠——与 DNF 原作构图一致。
- 相机锚点房间边界接线：默认 ±1200 从未按图喂入（竹林 0..1578，出口 1560——玩家东行会走出镜头）；进房（RunStarted）应用房间定义 Bounds 到相机锚点钳制。
- 全帧构图对照（M8-015 方法的补课）：以游戏内相机实拍 vs 源图逐块实看，不再只比 3 取样点。
- 验收：切片专项在新取景下全绿；全量回归绿（车辆相机测试断言随新默认值更新）；重打包后包内复验。
