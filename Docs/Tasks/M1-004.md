## 输入、输出与约定

在缓存上增加 PruneExpired(Now,Lifetime)、Consume(Action,Now,Lifetime,Out)、Reset；默认寿命0.150秒。Consume先清理再消费。

## 实现步骤

- [ ] 以显式传入的单调游戏时钟写边界测试，不读取系统墙钟
- [ ] 过期定义为 Now-PressedAt>Lifetime，恰好0.150秒仍可用；拒绝非有限时间和明显未来时间的输入
- [ ] Reset清空队列和序号水位，复位后的新会话可从序号1开始
- [ ] 不同动作过期不影响仍有效输入

## 独立验收

- [ ] t=1输入在1.150可消费，在1.151过期
- [ ] 过期Light和有效Launcher混合时只清除Light
- [ ] Reset后为空，序号从1重新接受；NaN时间不会进入缓存
