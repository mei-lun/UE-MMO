## 审核者重点断言（执行计划 §4 对照）

1. **067**：未登记/重复/定义级/旧 Run 死亡不改计数；2+3 通关回归（场景 JSON spawned=5 killed=5）。
2. **068**：无怪 Running 不存在；缺资源 Idle 可重触发、恢复后可进；开波被拒 → Failed。
3. **069**：两行 ID/地图/波次不混；负例报 room/field；schema1→2 迁移确定性。
4. **070**：新进程逐字段核对 8 项 true、幂等两遍一致；触发器软引用资产；缺失资产不回退 fallback。
5. **071**：白名单/图可终止/v1 显式迁移/未知拒绝（重复 ID、环、越界、区域、enum、schema3）。
6. **072**：重放/旧 run/暂停（时钟冻结回退）/效果拒绝无假完成；重入拒绝。
7. **073**：真实 2+3、恰 1 秒、Y 纵深、死亡失败、重试新 Run/SettlementId、retry 事件、重复 Overlap 无效；评估器重入与广播顺序两个修复。
8. **074**：最终包 `Artifacts/Package/Windows`；包内门禁 exit 0、链内零失败、八武器 8/8；**Rooms Cook 修复**；包内存档保全。
9. **076**：豁免净删除（名单 27→24，M5_004/M5_009 双环境绿）；FName 池根因注释。
10. **050**：p95/p99 预算、256 容量显式拒绝断言、100 轮回基线/内存平稳、stress-report.json+硬件记录。
11. **077**：账本 EndShot 接线（projectile+hitscan 双路径）；300 枪持续火力无静默拒绝；CapacityFull 可定位日志。
