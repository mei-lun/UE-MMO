## 根因（v5 包实证）

v5 包用户会话（2026-10-13 00:04，`UEMMO_2.log` + `OperationLog.log`）：

1. M5-057 修复生效：travel 后绑定恢复，Q 按键全部以 `Pressed Q (WeaponFire)`
   落地（开火授权通过），发射事务无一条 Warning 拒绝。
2. 起手武器 = 第一远程 = `weapon_hitscan_sample`（items.json 顺序），模式
   hitscan：交付是一次瞬时射线 + 伤害结算，**整条链路零可感知呈现**——
   无曳光、无枪口特效、无命中标记、无音效、无发射日志（现有日志均为
   Verbose，包内不显示）。
3. 对空开火（房内无敌人或未命中）时用户观感 = "Q 完全没反应"。
   H02 清单第 1 条明确要验收"射线"武器，不能靠换起手武器绕过。

## 边界

- 前置任务：M5-057（DONE）。
- 目标：每次成功发射（hitscan 与投射物两模式）都有可感知反馈：
  1. **hitscan 曳光束**：临时 Actor（引擎 Cube 拉伸，无碰撞，短寿命），
     逐弹丸从枪口原点到命中点或最大射程端点；
  2. **开火音效**：复用 Kenney Impact CC0 占位音效（与 M1-034 同源同装载路径）；
  3. **发射日志**：HandleWeaponShotCommitted 逐发 Display 级日志
     （模式/武器/弹丸数/命中数），包内可诊断"Q 到底有没有发射"。
- 不实现：正式枪声/枪口火焰/命中粒子等表现资产（按素材约束另议）；
  投射物模式视觉（16cm Cube 已有，M5-035）；伤害数字（M1-035 既有）。
- 分层契约：M5-026 钉死 ExecuteHitscan 为纯查询提交管线（不生成演员），
  曳光必须放在调用方呈现层（PrototypeCharacter 的 shot 提交回调）。
