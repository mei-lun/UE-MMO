# M6-020 离线衣装合成管线与全套动作图集

方案来源：接入方案 §4.2/§5.1/§9（P1 阶段）。依赖 [M6-019](M6-019.md) 的映射清单。

## 目标与边界

- 新增 `Scripts/DNFM/prepare_fighter_visual_set.py`：从 DNFM 恢复库 + M6-019 映射清单离线合成完整衣装动作帧，产出分页图集与 manifest。纯离线（Python + Pillow + sqlite 只读），不触 UE。
- 未支持变换（非单位缩放、旋转、特殊 shader/调色板）必须逐分支拦截报错或显式记录，不得静默降级（方案 §10）。
- 不在 Tick/运行时做任何合成。

## 实现步骤

1. 读取 ue_ready animation.json（帧时长/position/image_frame_index）+ atlas.sqlite（矩形/偏移/页）+ M6-019 映射；每个动作在统一角色坐标（脚底原点）合成 RGBA，记录逐帧 pivot/包围盒（方案 §4.2 第 4 条）。
2. 分页 ≤2048×2048，保留透明边距；超页动作另开页并记录，不静默缩小（方案 §4.2 第 5 条）。
3. 输出 manifest（上述契约）+ 每动作预览拼图（GIF/PNG 条带）供人工核对。
4. 确定性：同输入重跑字节一致；missing 显式输出。
5. 输出目录：`SourceAssets/Unpacked/DNFM130_5_8_202/Characters/Fighter/composite/`（git 忽略区）；原始证据 `Artifacts/Tasks/M6-020/<ts>/`。

## 验收条件

- 全部已确认动作合成成功：完整着装（身体/头发/上衣/下装/鞋及配置要求的手部/武器层）、缺层 0 或与 M6-019 missing 一致。
- 每帧 pivot 落在脚底允许范围（预览核对脚不滑动、切换动作脚底原点不跳动，方案 §9）。
- 图集无越界写入；引擎可用的 PNG；manifest 字段完整可机读。
- 预览条带人工查看确认姿势正确（写明查看了哪些文件）。
