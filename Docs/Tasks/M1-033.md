## 实现步骤

- [ ] 先测试冻结期输入可入队、冻结结束无补跑
- [ ] 保存/恢复受影响移动状态一次；重入停顿取max剩余而非叠加
- [ ] 不用全局TimeDilation；Reset/死亡清理停顿
- [ ] 验证空中停顿不让角色物理继续掉落而动画静止
