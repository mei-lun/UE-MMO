## 输入、输出与约定

玩家IsFalling时J路由aerial_01，地面J路由light_01；使用相同3D命中管线。空中命中受击敌人可设Z速度max(currentZ,160)，首次先限每浮空周期1次空中追击。

## 实现步骤

- [ ] 先测试相同输入在地面/空中的不同AttackId
- [ ] 确认空中命中框从抬高后的脚底计算
- [ ] 成功空中命中只给予一次小幅Z补偿，不每帧加速度
- [ ] 着地或Reset清空空中追击次数

## 独立验收

- [ ] 空中J不会开始地面light_01
- [ ] 不重叠的地面敌人不受空中攻击
- [ ] 浮空周期第2次空中追击被拒绝，落地后恢复可用
