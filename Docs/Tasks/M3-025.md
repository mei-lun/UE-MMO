# M3-025 · 刷怪敌人生产接线（AI 驱动/浮空/死亡销毁）

> 任务卡；进度以根目录 TASKS.md 对应行扇。

## 背景（用户第三轮试玩反馈）

包内日志证实：波次敌人正常生成、玩家攻击正常命中（MeleeEnemy 9 次命中、1 只死亡），但敌人站桩不动（无 AI 驱动、无目标绑定）、Z 上挑不产生浮空（MeleeEnemy 未复刻 LaunchCharacter 重载）、死亡无表现（数据死亡，Actor 站桩）。

## 实现要求

1. **WaveSpawner 生成后接线**：SpawnActor 出 AMeleeEnemy 后 `Possess`（SpawnActorDefault + AMeleeEnemyController）或以既有模式绑定控制器；`SetTarget(玩家 Pawn 弱引用)`（玩家经 Session SetPlayer 已知/GetPlayerCharacter——取可用路径，报告写明）。
2. **AMeleeEnemy 复刻 M1-022 浮空重载**：`LaunchCharacter(FVector, bool, bool)` override（Z 上挑冲量生效），与 AirComboCount 记录（对齐 TrainingEnemy 的 M1-022 模式，最小实现）。
3. **死亡销毁（原型标准）**：OnDied → 停 AI/关碰撞 → 延迟 2s Destroy（或立即——报告写明选择）；死亡从 AliveIds 移除（M2-008 既有）不受影响。
4. **目标死亡**：目标 Pawn 死亡 → 敌人回 Idle（M2-002 既有），不崩溃。
