# M8-003 P01-B 鬼剑士源依赖核实

对应 07 计划 §4 候选表"鬼剑士"行与 P01。目标：为第二职业接入提供可解析的精确源键清单。

范围（全程只读源库）：

- `script/character/swordman/animation/` 全部 .ani 枚举（不止 rest/move/attack1..3/jump/die），逐动作帧数/时长/变换。
- 衣装/头发/武器层：找到默认固定衣装组合（参照格斗家 0000a 方法：chr 配置 + .equ → .img），验证各层与 body 帧平行性；明确层序；区分并排除 `atanimation` 的另一套身体，记录两者判定依据。
- 基础状态候选：rest/move/dash/jump/jumpattack/down/die + 受击/起身对应动作（按 fighter 的 damage/overturn 线索在同库定位）。
- 六技能候选（上挑、突刺、连续移动斩、下劈、远程斩击、格挡/反击为功能意图）：在 swordman 动作/特效物件中按证据提名，每招给"身体动作 + 效果/声音依赖 + 可实现策略"三要素；证据不足的招式如实标注候选级别，最终由资源门冻结。

验收：`Data/DNFMReplica/verify/swordman.json` 记录衣装层映射（含武器层）、基础动作集、六技能候选与依赖；gaps 逐条列出；合成预览 PNG 交协调者实看。不混入错误身体集；零写入 DNFM 目录。
