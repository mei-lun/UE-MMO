# M6-025 固定开发包验收（P5）

方案来源：接入方案 §8（P5）、§9 性能记录。依赖 [M6-024](M6-024.md)。

## 目标与边界

- 新进程重载 + Cook + 固定包：唯一输出目录 `Artifacts/Package/Windows`（覆盖更新，不建并行目录）；`Scripts/Build.ps1`、`Scripts/Test.ps1`（含 -Render）、`Scripts/Package.ps1`、`Scripts/TestPackage.ps1` 全通过。
- 现有回归全量跑（基线 919 项）；包内专项（公会图/训练场）通过。
- 记录 3D 模式与 DNFM 画面模式同机、同场景/敌人数的帧时间与加载开销对照（方案 §9，至少自动化可测的指标；不能只报 PNG 磁盘大小）。
- 包内截图：固定镜头下玩家完整衣装在公会图前/中/后纵深、左右朝向、地面/跳跃（方案 §8 P2 通过条件复验）。
- 清理旧包前保护用户存档与验收证据（AGENTS.md 打包规则）；不改默认显示模式决定（留用户）。

## 验收条件

- 全部命令 exit=0 且本次生成 JSON success=true；exe SHA256 记录；源码提交 SHA 记录。
- 截图人工查看（记录路径与观察结论）；存档完好（数量不减少）。
- 报告明确"自动验收通过 ≠ 用户试玩通过"；用户试玩事项列出（固定包路径、启动方式、gate 开关说明）。
