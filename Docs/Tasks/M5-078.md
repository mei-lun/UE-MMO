# M5-078 · 投射物服务容量陈旧窗口核算

- 前置：M5-050；预计 30–60 分钟（含设计决定）。M5-050 调查发现的生产缺口②：`FProjectileWorldService::MaxLiveProjectiles=256` 的活数以弱引用有效性计数（`ProjectileWorldService.cpp:123-133,214-225`），**Destroy 后未 GC 前的退役弹体仍占容量**（"陈旧窗口"）。生产默认 60s GC 间隔下，平均退役吞吐 >≈4.3 弹/s 即周期性触发 `CapacityFull` 拒发；200 并发+0.5s GC 间隔实测 ≈233<256 勉强可行。
- 选项（需用户/设计拍板后实施）：a) 退役时显式从弱引用簿记剔除的接口；b) 容量按"活跃（非 pending-kill）"计数；c) 缩短该类对象回收间隔。默认不做对象池（M5-050 卡既定）。
- 验收：选定方案后压测 200 并发在默认 GC 设置下无拒发；方案取舍与数字记录进报告。
