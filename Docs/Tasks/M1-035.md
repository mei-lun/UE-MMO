## 实现步骤

- [ ] 先测数字过期、容量和死亡后目标失效
- [ ] 用世界位置投屏显示数字，值来自DamageApplied实际扣除量
- [ ] reset清空连击/数字，HUD解绑旧目标事件
- [ ] 保持输入提示可读，不被调试叠层挡住

## 独立验收

- [ ] HP100→90时显示10，不显示配置原始值以外的假数
- [ ] 超过32个数字淘汰最早且无失效引用访问
