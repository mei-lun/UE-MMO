# M5-073 · 区域与波次事件接入生产房间

- 前置：M5-072；预计 30–90 分钟，地图与 Session 改动过大则先拆卡。首个生产接线必须保持现有房间玩法。
- 参考：`RoomTrigger.cpp:144-216`、`RoomSessionSubsystem.cpp:478-669,780-820`、`WaveSpawner.cpp:216-430`、`RoomRetryService.cpp:14-103`、`Scripts/Editor/create_room_assets.py`。
- 实现：仅生产房资产选择规则路径：玩家首次进入触发体后启动 Run 并发布区域激活事件；波次全出生且全死亡时发布 `WaveCleared`；玩家死亡发失败事件；规则请求仍交现有 Session 开波/结算。非规则测试夹具保留旧直接 `BeginWaves` 路径。重试生成新 Run 后从可信的同一区域激活语义重新开第 0 波，无需再制造第二次物理 Overlap；该事件标记为 retry 来源。离房、地图卸载取消旧事件。使用 UE 编辑器 API 保存地图，并独立进程重载验证。
- 验收：初入仅第 0 波两敌；其均死且 pending=0 后恰好 1 秒启第 1 波三敌；玩家死亡 Failed、重试新 Run、新 SettlementId；旧死亡/旧延时/重复 Overlap 无效；Y 纵深区域内外正反例；训练场仍无自动刷怪。测试 `UEMMO.Tasks.M5_073.*`。
