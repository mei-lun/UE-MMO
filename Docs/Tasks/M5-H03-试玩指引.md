## 正确流程（先地图，后生成）

1. 启动 `Artifacts\Package\Windows\UEMMO\Binaries\UEMMO.exe`。
2. **在 Map Select 界面选一张图进入**（推荐 `SystemTestRoom (config-driven)`，空旷无敌人；想练战斗就选 TrainingArena）。按提示的 Enter 键进入。
3. 进图后按 **`~`（反引号）呼出控制台**，输入：
   ```
   UEMMODebugVehicle 1
   ```
   ——在**你面朝的方向约 5.5 米**处生成样例单座地面车（HUD 第 4 行有此提示；放歪了可 `UEMMODebugVehicle 2` 清掉重来）。
4. 用**方向键**走到车边（≤3 米），按 **`V`** 进入。首次进入时炮塔自动武装（无需手动）。

> 注意：菜单界面（Map Select）里车是进不去的——菜单会拦输入，这是预期行为；务必先进图。

## 试玩清单（对应卡面 5 项）

1. **进入与司机状态**：`V` 进入后确认：镜头切到车辆跟随视角、角色不可再自由走动（司机状态可辨）。
2. **驾驶（纵深+边界）**：方向键驾驶。确认：X 横向、Y 纵深（不锁 Y）、斜向不加速、撞墙不穿墙（贴墙停/滑）、松键滑行刹停、**车不飞行/不跳跃**。镜头跟车不遮挡。
3. **炮火**：`Q` 开炮（爆炸火箭，弹匣 3、储备 12；`T` 装填）。确认：车体出弹、命中爆炸、弹药递减、不自伤（友伤过滤按司机阵营）。
4. **退出/再进入/堵门**：`V` 在安全位下车（落在车侧 2.5 米）→ 再 `V` 进入。把车贴墙使下车点被堵再按 `V`——**应拒绝下车且不穿墙**（留在车内），开离后可正常下车。
5. **清理面**：a) 司机死亡（进 TrainingArena 被敌人击杀，或战斗中死亡）→ 座位释放、控制恢复（`F2` 复活）；b) 车辆被毁（HP 250，让敌人/爆炸打）→ 司机安全恢复、车不再可开火；c) `F2` 房间重试 / 地图退出重进 → 无幽灵座位（可再生成新车正常进入）。
