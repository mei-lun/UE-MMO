## 试玩清单（对应卡面 5 项）

1. **进入与司机状态**：走近车辆（≤3 米），按 `V` 进入。观察：镜头切到车辆地面锚点（更近的跟随视角）、HUD 输入提示变化、角色不可再自由走动（司机状态可辨）。
2. **驾驶（纵深+边界）**：方向键驾驶。确认：X 横向、Y 纵深走位（不锁 Y）、斜向不加速、撞墙不穿墙（会贴墙滑动/停止）、松键滑行刹停、**车不飞行/不跳跃**（首版地面平台）。镜头始终跟车不遮挡。
3. **炮火**：按 `Q` 开炮（爆炸火箭，弹匣 3 发、储备 12；`T` 装填）。确认：炮口从车体出弹、命中爆炸有伤害反馈、俯仰固定水平（首版无俯仰输入，schema 有 -20°..60° 钳制位）、弹药计数递减、友伤过滤按司机阵营（朝 NPC 打会命中，无自伤）。
4. **退出/再进入/堵门**：按 `V` 在安全位置下车（落在车侧 2.5 米）；再 `V` 进入。把车开到墙边使下车点被堵（车体贴墙、下车位在墙内）再按 `V`——**应拒绝下车且不穿墙**（角色留在车内），开离后可正常下车。
5. **清理面**：a) 驾驶员死亡（让敌人击杀或控制台伤害）→ 座位释放、控制恢复；b) 车辆被毁（炮火/敌人打爆 HP 250）→ 司机被安全弹出、镜头回角色、车不可再开火；c) `F2` 房间重试 / 地图退出重进 → 无幽灵座位（可重新进入新车）。司机死亡后用 `F2` 复活再试。
