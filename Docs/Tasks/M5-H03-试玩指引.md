## 流程（3 步）

1. 启动 `Artifacts\Package\Windows\UEMMO\Binaries\UEMMO.exe` → 主菜单选 **SystemTestRoom (config-driven)** 进图（想顺路试波次房可选 CombatRoom01/02，与载具验收无关）；
2. 按 **`F8`**——车生成在你身边（灰色方块体，HUD 第 4 行有提示）；
3. 走近按 **`V`** 上车 / 再按 **`V`** 下车。**上车后照常移动**：方向键走路，车套在你身上跟着走；`Q` 发车炮（爆炸火箭，弹匣 3 储备 12）；`T` 装填；`C` 跳跃带着车跳。

## 试玩清单（对应卡面 5 项，按骑乘模型）

1. **上车与司机状态**：`V` 上车后确认：车套在身上跟着你走、`Q` 打出去的是**车的炮**（不是你的枪）、松开后可再 `V` 下车。
2. **移动（纵深+边界）**：方向键照常走路，车跟随。确认：X 横向、Y 纵深（不锁 Y）、撞墙不穿墙（人和车一起被挡）、**不飞行**（跳跃是角色自己的跳，车跟着）。
3. **炮火**：`Q` 开炮。确认：弹从车头前方发出、命中爆炸有伤害数字、弹药递减、`T` 装填、不会炸到自己。
4. **下车/再上车**：`V` 下车——车留在原地，你恢复普通走路；再走近 `V` 上车。
5. **清理面**：a) 被敌人打死（进 TrainingArena）→ 座位释放、控制恢复（`F2` 复活）；b) 车被毁（HP 250）→ 车消失/不可再开炮，人不受伤；c) `F2` 重试 / 换图重进 → 可再 `F8` 生成新车正常上下。
