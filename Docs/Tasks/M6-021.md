# M6-021 DNFM 角色画面组件与数据资产类型（C++，P2 代码层）

方案来源：接入方案 §3/§5/§7。依赖 [M6-020](M6-020.md) 的 manifest 契约（契约冻结即可开工；资产导入在 M6-022）。

## 目标与边界

- 新增 `Source/UEMMO/Character/DNFMCharacterVisualSet.{h,cpp}`：`UDNFMCharacterVisualSet : UPrimaryDataAsset`（页纹理引用、逐动作 `UDNFMActionClip`/结构：帧时长、UV、Pivot、页号、事件、源哈希）+ 离线 manifest 的运行时反序列化辅助（编辑器导入脚本用）。
- 新增 `Source/UEMMO/Character/DNFMCharacterVisualComponent.{h,cpp}`：只负责画面/帧选择/定位（方案 §3）；输入是现有状态事实，不建第二战斗时钟。
- `PrototypeCharacter` 接线：新 CVar `UEMMO.PlayerDNFMVisual`（默认 0=现有 3D 骨骼显示不变；1=DNFM 画面模式），替换旧 `TickOriginal2DVisual` 的 Spine 待机循环路径；3D 回退保留。
- 不改 Combat 数值、不新增伤害判定；不决定默认模式（验收后由用户定，方案 §3）。

## 实现要点（方案 §5.1/§5.2）

- 脚底锚点：P = 胶囊中心 − 当前后半高（随跳跃真实 Z）；平面世界朝向固定（相机 Right/Up 向量），Actor 0°/180° 只提供 Facing，不二次旋转（避免双重翻转/侧面消失）。
- 统一 s（厘米/像素）由站立帧头顶高度与项目目标身高标定一次，所有动作共用；禁止逐帧自动缩放。
- 世界定位公式：`WorldPoint = P + R * Facing * (x - PivotX) * s + U * (PivotY - y) * s`。
- Unlit 材质入口、页/UV 切换、透明度模式参数化（Masked 优先评估）；每角色首版仅一个合成绘制组件。
- 软阴影（随脚下地面，跳跃按离地高度调透明度/范围）作为接地提示。

## 验收条件

- `Scripts/Build.ps1` exit=0 且 JSON success=true。
- 新增/更新自动化测试：页与帧选择、Facing 单次翻转、脚底锚点计算（地面/跳跃 Z）、复位清理；`Scripts/Test.ps1` 通过。
- 3D 默认路径不回归（gate=0 时行为与 M6-016 基线一致）。
