## 按卡逐项要点（对应卡内试玩清单 1–5）

1. **UI 选装八武器**：训练剑、普通枪（实体弹丸）、点射、散弹、直线、抛物线、追踪、爆炸——全部经 UI 装备，不用控制台。
2. **开火/换弹**：Q 按住/点按/连射手感；菜单、背包打开、死亡时后台不得射击；T 仅在合法时换弹。
3. **弹药账目**：loaded/reserve 显示；散弹多弹丸一发耗多弹；空弹/中断/换武器不赠弹。
4. **弹丸表现**：普通弹是**有体积的橙色弹头**独立飞行（约 1200cm/s、2s 寿命），碰撞才扣血，命中/超时即消失；不能是整段闪烁柱/线（v11 已按你要求移除）。纵深打空、薄墙阻挡、穿透数、爆炸范围、墙后遮挡逐一看。
5. **重启边界**：关闭重开游戏，弹药不持久化是**预期**（D 段范围），别当缺陷。
