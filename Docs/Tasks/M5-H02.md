## 试玩清单

1. 通过UI选装备近战/实体步枪/点射/散弹/直线/抛物线/追踪/爆炸武器，不靠控制台。2026-10-17用户要求普通枪采用独立弹丸实体，取代旧射线光柱；先在激活区外选枪。
2. Q按下/松开测试单发、连射、点射，T换弹；在菜单/背包/死亡时不能后台射击。
3. 观察loaded/reserve，多弹丸一发耗一弹；空弹/中断和换武器不赠弹。
4. 检查纵深打空、薄墙阻挡、穿透数、爆炸范围和墙后遮挡。
   普通子弹应有飞行过程、配置速度和寿命，碰撞后才扣血，命中/超时后消失；不能只有整段柱体闪烁。
   用户明确拒绝v11线状拖尾。M5-063要求看清有体积的弹头本身在飞行，不能靠线段或运动模糊代替；命中/超时销毁，回到菜单和复位无残留。
5. 关闭重开只确认B段已声明范围：弹药持久化仍待D段，不把暂不保存误当验收已完成。
