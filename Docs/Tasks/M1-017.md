## 输入、输出与约定

ComputeHitBox(FeetLocation,Facing,Definition)；定义中的HitOffset是脚底原点相对偏移，默认(95,0,90)cm，半尺寸(85,50,70)。仅X随Facing镜像。

## 实现步骤

- [ ] 先测试同一地面原点左右方向中心和半尺寸
- [ ] 采用明确FeetLocation，不能再用胶囊中心重复加90cm
- [ ] 使查询轴固定世界X/Y/Z，避免人物模型的-90°校准影响框方向
- [ ] 提供调试数据结构包含center与extent

## 独立验收

- [ ] Feet=(100,20,0)，Facing+1中心=(195,20,90)，Facing-1中心=(5,20,90)
- [ ] 左右方向Y和Z保持一致
- [ ] 高度原点从胶囊脚底计算，跳跃时同步抬高
