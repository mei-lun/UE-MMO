## 输入、输出与约定

只读复核现有工程，输出当前 HEAD、工具链、既有未提交改动和本次测试结果；不修复或重写无关游戏功能。

## 实现步骤

- [ ] 先运行 git status --short 与 git rev-parse HEAD；存在他人修改时记录文件，不覆盖
- [ ] 依次执行 CheckEnvironment、Build、Test、Test -Render，最后复制本次报告与截图到本任务时间戳目录
- [ ] 实际查看截图，记录角色、场地和 HUD 是否可见；将环境差异写报告

## 独立验收

- [ ] 四个脚本都实际退出 0，各自本次报告存在且 success=true；渲染报告 rendering=true
- [ ] 报告记录至少一条真实观察与键盘尚未手工验证的边界
- [ ] 如果基线失败，本项标 BLOCKED 并登记修复任务，不修改结果文件冒充通过

## 验证入口

使用已存在的 Scripts/CheckEnvironment.ps1、Build.ps1、Test.ps1、Test.ps1 -Render。命令逐条执行，成功后保留原始报告副本；本项不要求 TestAutomation。
