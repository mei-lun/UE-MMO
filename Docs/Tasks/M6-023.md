# M6-023 CombatPresentation 统一显示目标与战斗同步（P3）

方案来源：接入方案 §6.1/§6.2/§6.3/§9。依赖 [M6-021](M6-021.md)、[M6-022](M6-022.md)。

## 目标与边界

- `CombatPresentationComponent` 接入 DNFM 显示目标：绑定既有 `OnStarted/OnFinished/OnHitStopChanged` + `GetSnapshot()` 兜底；状态优先级：死亡 → 倒地/起身/受击 → 当前攻击 → 跳跃阶段 → 地面移动/待机。
- 攻击时间线由 `AttackId + InstanceId + Frame` 决定片段采样（不用 World 时间另跑时钟）；为每个攻击建立分段映射表（起手/命中/收招 ↔ 源片段时间 ↔ 目标逻辑窗），视觉命中姿势必须落在现有伤害窗内（如 light_01 26帧 [7,11) ↔ attack1.ani 3帧 400ms）。
- 事件去重 `(ActorId, AttackInstanceId, EventId)`；HitStop 冻结画面与事件；暂停/中断/死亡/切关取消旧实例；死亡片段播完保持末帧。
- 画面切换不扣血/不给无敌/不解锁移动；不改玩法数值。

## 验收条件

- 自动化测试：攻击同步（AttackId/InstanceId/Frame 采样）、HitStop 冻结、取消/中断/死亡/复位不残留、事件去重、低帧率跨帧区间；全部通过。
- `Scripts/Test.ps1 -Render` 实际截图：待机/移动/攻击/跳跃画面与姿势正确（人工查看图片并记录路径）。
- 命中窗同步断言（显示命中帧 ∈ 现有 active 窗）。
