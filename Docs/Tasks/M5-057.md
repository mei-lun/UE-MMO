## 根因（v4 包日志证据）

`Artifacts\Package\M5B-2026-10-10-v4\Windows\UEMMO\Saved\Logs\UEMMO.log`（2026-10-10 11:38 会话）：

1. 启动直接进 L_CombatRoom01（boot 世界）→ M3-011/012 staging 发放 10 件 + 装备远程 →
   `weapon mount applied (bound=1, generation=2)` —— 首世界一切正常。
2. 同帧 EnterRoom 触发二次 `Browse L_CombatRoom01`（travel 重载）→ 新世界 pawn
   `bound=0, generation=1`。
3. 用户开背包：`10 items, 0 equipped ids` —— 背包在 UProfileSubsystem（GameInstance 级，
   跨 travel 存活），装备权威 FEquipmentModel 在 HUD（World 级，travel 销毁）。
4. 新 pawn BeginPlay 的 `RefreshWeaponMountFromEquipment` 读新 HUD 的空装备模型 →
   WeaponInstance=nullptr → bound=0 → Q 退化技能槽。
