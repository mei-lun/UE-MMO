### 2.2 M3-032 占位动画升级尝试记录（2026-10-05）

3. **97 条入库动画再筛（受击/倒地视角）**：HitReact 8 条（Rifle/HitReact，带武器姿态）、Death 6 条、MM_Dash 1 条；**无 GetUp 类**。可用于未来“上挑后受击/倒地”缺口的候选：MM_HitReact_Front_Hvy_01（0.800s）、MM_Death_Front_01/02（1.100s/1.133s，倒地）、MM_Dash（0.967s）；死亡与倒地恢复仍需单独规则（缺口 3）。

即：免费层 86 条动画（43+43）中没有专用上挑/空中攻击动作，两个占位维持不变。若后续要使用 Quaternius 库（受击/倒地优先），需要先做 IK Retarget 管线，见缺口 3。

## 4. M1 必须验证的美术缺口

1. 专用上挑动作：M1-036 定格预览证实 MM_ChargedAttack 生效窗内为水平直拳，无上挑挥击轨迹（详见 2.1）；M3-032 已穷尽免费渠道（Quaternius 两包免费层 86 条枚举 + 引擎/模板扫描 + 97 条再筛，详见 2.2）无替代，**维持占位，待人工指定来源**或用户接受现状。
2. 空中追击动作：M1-036 定格预览证实 MM_Attack_03 生效窗内为单腿支撑高踢（支撑脚触地）；浮空播放会出现支撑脚悬空违和（详见 2.1）；M3-032 同上穷尽免费渠道无替代，结论同上。
3. 空中受击和倒地恢复：区分死亡，不重复播放死亡动画作为复活。候选已在库内：MM_HitReact_Front_Hvy_01 / MM_Death_Front_01/02（97 条清单，受武器姿态影响需预览）、UAL2 Hit_Knockback（CC0，Quaternius 骨架需 retarget）；**无 GetUp 动作**，倒地恢复仍无素材。
4. 模型朝向与武器：首轮徒手；武器职业需新增握点与武器素材。
5. 脚步与命中音频触发：声音本身已具备，时机和并发限制未实现。

缺口不阻止 M0 运行。M1 的机制可以用现有动作占位验证，但用户对动作观感验收前不能声称连招美术完整。

## 6. 资产清单字段与入库流程

manifest.json 记录 pack id、作者、来源 URL、本地路径、许可证据、SHA256、是否为启动必需项和实际状态。实际文件库存与动画库存独立保留。

新增流程：查作者原站→确认免费层→保存原包→核对许可→SHA256→解压至 SourceAssets/Unpacked→UE API 导入到独立命名空间→记录骨架/材质引用→保存→重启重载→渲染截图→提交 LFS 资产和文本清单。

禁止直接覆盖同名 Skeleton、未经预览批量重定向全部动作、在文件管理器中改 UE 资产文件名、把未下载包标成“已准备”。
