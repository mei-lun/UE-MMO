## 5. 发现并修复的问题

1. PowerShell 直接传含小数点的编译器参数被拆分：改为脚本数组传参。
2. MSVC 14.38 在 UE 模板语法失败：安装兼容 Build Tools，未修改引擎代码。
3. Python Rotator 位置参数与 C++ 顺序不同，预览角色横躺：改关键字参数，重载和截图确认。
4. 瞬态 play_animation 不保存动作引用：设置 animation_data.anim_to_play 后保存，重启重载确认。
5. 渲染测试可能使用旧截图：渲染前移除旧图，要求本次 rendering=true 和新 PNG。
6. 缺少 Pawn 可能无限等待：游戏内缺失计时加失败退出，进程层 600s 超时。
7. 下载中断污染最终 ZIP：先写 .partial，校验成功再重命名；解压检查四个必要声音。
8. 中断复制导致素材目录不完整：补齐缺失模板文件；加载检查加入实际使用的跑步动画。
9. 前栏过低可跨出场地：加入独立不可见高碰撞边界。
10. 光源优先级警告：明确主 DirectionalLight 优先级，最终截图无此警告。
11. 按下相反方向键：Enhanced Input 使用 Cumulative 累加，W/S、A/D 可相互抵消。
12. Start-Process 退出码在此宿主返回空：改为 System.Diagnostics.Process、异步读取标准输出和错误、显式超时与退出码。
