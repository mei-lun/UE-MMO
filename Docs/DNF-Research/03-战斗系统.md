# 战斗系统

## 静态组件

- 角色基础：pvf/character/**/*.chr.json 包含 HP/MP、物魔攻击与防御、抗性、移速、攻速、施法速度、跳跃、普通攻击动作和武器音效引用。
- 攻击与动作：pvf/character、pvf/monster、pvf/passiveobject 下的 .act.json、.atk.json、.obj.json、.mob.json、.ai.json；完整条目清单见 reports/pvf-manifest.json。
- 技能参数：pvf/skill/**/*.skl.json 中的输入、冷却、MP、等级和效果字段。
- 状态和回调：pvf/appendage/**/*.apd.json 与 code/squirrel/**/*.nut。实际脚本出现 onAttack_PassiveObject、sq_getJob、sq_requestBuySkill、sq_LoadSkillEffectAni 等函数或调用。
- 视觉及音效：assets/raw/npk/character-effects、assets/raw/npk/monsters、assets/audio/soundpacks。

从静态结构可推断：职业配置提供基础参数，动作与攻击文件关联动画及判定数据，技能文件提供特定技能参数，脚本处理部分状态和被动对象回调，客户端程序调度执行。此处没有证明完整伤害公式、判定盒实时行为、连击优先级或同步逻辑。

本说明用于研究现有客户端结构，不表示这些战斗内容已在 UE-MMO 中实现。
