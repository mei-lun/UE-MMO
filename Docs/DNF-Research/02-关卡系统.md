# 关卡系统

pvf/dungeon/**/*.dgn.json 中解析出 338 个地城定义，reports/dungeons.csv 索引入口等级、地城尺寸、起点、BOSS 房、过场及小地图引用。

pvf/map/**/*.map.json 中解析出 2,887 个地图定义，reports/maps.csv 索引地城号、瓦片和背景字段。同区域的 tile/*.til.json、animation/*.ani.json 保存地块和动画配置。怪物与场景物体见 pvf/monster、pvf/passiveobject。

例：pvf/dungeon/act1/lorien.dgn.json 声明最低等级 1、2×3 地城网格、起点/首领位置、Map/MiniMap/Act1.img 和 Map/CutScene/Lorien.img。映射结果是 sprite_map_minimap.NPK 与 sprite_map_cutscene.NPK，对应解码 PNG 在 assets/images/sprite/map。pvf/map/grakkarak/1002.map.json 展示房间地图中的 tile、背景动画和路径门位置等字段。

原始地图美术包按特征名保存在 assets/raw/npk/maps，配置到 NPK 的精确 IMG 对照见 reports/resource-references.csv。地城目录、地图编号与资源链接可由静态文件证明；实际关卡调度算法未经过运行时验证。
