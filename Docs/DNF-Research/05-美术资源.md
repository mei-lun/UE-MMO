# 美术、音频和视频资源

## 原始存档

assets/raw/npk 根据文件名特征分类为地图、怪物、职业与装备、特效、界面及其他。保留每个原始文件名；逐项 SHA-256 见 reports/raw-assets-manifest.jsonl。assets/img 从全部 4,085 个 NPK 中拆出 137,471 个 IMG 容器文件，按原内部特征路径命名；逐项 SHA-256 见 reports/img-files.jsonl，提取结果见 reports/img-summary.json。reports/image-packages.csv 列出各包大小、IMG 数与帧条目数；reports/npk-inventory.json 记录内部 IMG 名称，例如 sprite/character/swordman/effect/skillicon.img。

assets/raw/loose 收录 Music、Video、TCLS、Shader、Fonts、start 中的音视频、图片、字体与界面相关文件。assets/audio/soundpacks 是从 86 个声音包解出的 15,559 个 OGG。assets/video 是 1,103 个从 Neople Video 封装解出的 RIFF 视频，原文件也已存档。

VFS、PAK、XMLZ 等小型容器已原样存于 assets/raw/loose，但未逐项证明其内部是美术资源；不要将这些文件视为已解码素材。

另外，从 3 个 ZIP 中筛出美术/字体相关成员，并识别两个误标为 .bin 的 JPEG，存于 assets/extra；明细和校验值见 reports/extra-assets.json。其余 ZIP 成员主要是插件二进制或配置，未混入美术目录。

## 可查看图像与命名

assets/images 包含已解出的地图小地图/过场、部分地图装饰、界面、职业特效和技能图标。目录继承 IMG 内的特征路径，末级数字为帧索引；链接帧保留在 .links.json。用配置中的 IMG 原文到 reports/resource-references.csv 查精确包和预期 PNG 目录。

NPK 索引约 18,464,389 个帧条目，全量逐帧 PNG 需要大量文件和空间。本交付保留全部原包、拆出的全部 IMG 容器与 IMG 索引，附 tools/dfo-npk-extractor-bun 提取器和已解码样本。PNG 文件数不是美术帧总数。
